# 北师大版小学数学二年级 AI 学习助手

本目录是独立维护的数学辅导网站项目，与 apps/ad-studio-desktop/ 完全隔离。

## 产品方向
- 目标是让孩子真正独立掌握知识，并用可比测评验证进步；不是只做会回答题目的聊天机器人。
- 交付手机浏览器可访问的中文响应式网站，不要求本地模型。
- 从头自研；开源项目只用于研究和借鉴设计，不复制候选源码。
- 首选用户已有 DeepSeek API，密钥只存服务器端。
- 应用层不设置 Token 配额/预算上限，按实际调用量计费；技术故障重试有退避和恢复机制，避免死循环。
- 不预先承诺提分；用独立测验、迁移题、延迟复测及学校成绩对照诚实评估。

## 核心学习规则
- 每题每回合最多 3 次主动提示，提示由浅入深。
- 答错、用过提示或看过讲解的题必须重新出现；重做时不展示旧提示。
- 提示后答对不等于独立掌握；原题重做、迁移题、无提示测验和延迟复测分别记录。
- 错误诊断必须有证据；原因不明确时用鉴别题，仍不明确则标记 unknown。
- 系统记录教学策略及选择原因，并验证策略是否有效；连续失败时调整策略或检查前置知识。
- 每单元有基线、结束平行测验和延迟复测；期中、期末有覆盖已学内容的累积测验。
- 家长报告真实呈现成绩变化、提示依赖、迁移和延迟保持；没有进步时补弱并复测。

## 自研与参考项目
从头自研本网站。开源项目只用于借鉴架构、儿童 UX、OCR/视觉、教学设计和测试方法；不复制未经核实许可的候选源码。第三方依赖、字体、图片、音效和课程内容分别核查许可。OpenMath 的许可证文件缺失只意味着不复制其源码，不再阻塞自研。

## 进度纪律
开发不临时增加功能、不重复实现已有能力。每项任务先写目标、范围、依赖、验证步骤和通过条件；完成后附代码/测试/人工验收证据。只有已验收任务计入加权进度。软件交付完成率、教学闭环有效性和孩子学习效果分别统计。CI 绿灯不等于应用验收通过。

## v2.1 强制实现与验收约束

以下不是可选建议，而是首期产品必须实现并通过验收的行为：
- 每日学习时间由家长设置上限，默认建议约 10 分钟但不强迫学满；系统按掌握证据、知识点重要性、前置依赖和近期失误安排有限任务，到时不再开启新任务，未完成项顺延。
- 孩子已稳定掌握的内容自动减少练习；未掌握内容优先补弱；每道题必须有诊断、教学、验证或复习目的。
- 空白试卷、孩子已作答但未批改的试卷、老师已批改试卷均可拍照上传。识别不确定处必须让家长/孩子确认，不能把 OCR 猜测直接作为事实。
- 拍照题目与教材学习共用知识点档案、诊断、最多 3 次分层提示、错题重做、无提示变式和延迟复测。
- 如果教学策略无效，系统必须改变策略或检查前置知识；不能只给出“建议调整”的文字。
- 验收必须包含自动化行为测试、手机端端到端测试和学习测量证据。文档描述、部署成功或 CI 通过均不等于功能实现。

## 中国儿童体验基线
简体中文原生、贴近中国小学教材与课堂/家庭生活情境；视觉温暖清晰、灵动耐看，避免过度动画；大字、易触控、手机优先，可选普通话朗读和安静模式。趣味用于帮助理解，不以强制签到、公开排名或刷题量制造压力。所有此前确定的首期功能都保留，实现可分阶段但不得从需求范围删除。
