# 北师大版小学数学二年级 AI 学习助手

本目录是在 `konggu888/ecommerce-agent` 仓库中独立维护的数学辅导网站项目，与现有 `apps/ad-studio-desktop/` 完全隔离。

## 产品方向
- 最终交付为手机浏览器可访问的中文响应式网站；不要求安装本地 AI 模型。
- 优先复用成熟的开源数学辅导项目；不从零重写已经成熟的课程、答题、提示和进度能力。
- 首选接入用户已有的 DeepSeek API，密钥只存服务器端。
- 应用层不设置 Token 配额/预算上限，按实际调用量计费；充分投入 AI 进行错题诊断、教学调整、变式题生成和质量复核。
- 成绩提升是核心目标，但必须通过基线、独立迁移题和延迟复测验证，不承诺未经测量的分数提升。

## 开发前必须遵守
先完成项目选型、许可证和上游能力核查；选型门禁通过前不迁移上游代码或开始应用实现。OpenMath 是第一候选，但许可与运行状态仍须有证据确认。README 徽章不等同于已确认的正式许可证。

## 固定计划（必须按文件执行）
- `docs/PRODUCT_SPEC.md`：产品目标、首期范围与明确排除项。
- `docs/TECHNICAL_ARCHITECTURE.md`：复用优先架构、DeepSeek 适配、安全与部署。
- `docs/AI_TUTORING_PROTOCOL.md`：教学循环、错误分类、变式题、掌握证据与间隔复习。
- `docs/CURRICULUM_PLAN.md`：教材核对、课程映射、题库和内容质量标准。
- `docs/PRIVACY_AND_COST.md`：Token 用量、密钥、儿童数据和故障处理规则。
- `docs/IMPLEMENTATION_PLAN.md`：固定 32 项任务、权重、验收和范围变更控制。
- `docs/PROGRESS_DASHBOARD.md`：当前进度、阻塞项和真实测试状态。
- `docs/ACCEPTANCE.md`：首期验收清单。
- `docs/CHANGELOG.md`：每轮变更记录。
- `upstream/OPENMATH_REFERENCE.md`：上游项目、源码审查和许可证据。

## 进度纪律
开发过程中不临时增加功能、不重复实现已存在的能力。每个任务先写目标、范围、依赖、验证步骤和通过条件；完成后附代码/测试/人工验收证据。只有已验收任务计入加权进度。CI 绿灯不等于应用完整验收。任何新想法先列入后续候选，只有批准新计划版本后才能进入首期范围。

## 当前状态
目前是规划基线阶段，不是可运行产品。初始 YAML 是自编草稿，尚未证明与 OpenMath 的真实课程 schema 兼容；上游许可、运行测试、DeepSeek API 调用和手机端测试均未完成。详情以进度看板为准。
