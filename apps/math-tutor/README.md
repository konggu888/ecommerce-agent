# 北师大版小学数学二年级 AI 学习助手

本目录用于在 `konggu888/ecommerce-agent` 的独立分支中启动一个**独立学习项目**，避免修改现有电商广告桌面应用。

## 项目目标
- 以孩子实际使用的北师大版小学数学二年级教材为课程主线。
- 用分步提示引导孩子审题、识别数量关系、选择方法，而不是直接报答案。
- 为错题记录具体错误类型，安排同知识点的换问法、干扰条件和迁移练习。
- 根据多次不同题型的表现安排复习，不以背会原题作为掌握标准。
- 优先支持本地学习记录，并提供家长查看薄弱点的能力。

## 目录约定
- `curriculum/beishi2024/zh/concepts/`：中文结构化课程与自编题目。
- `docs/`：选型、教材版本核验和验收规则。
- `upstream/OPENMATH_REFERENCE.md`：上游项目与复用边界说明。

## 重要状态
当前是启动提交：加入了课程样例和验收规则，**尚未完成 OpenMath 程序源码迁移，也未声称测试通过**。开始迁移前发现上游仓库 README 有 Apache 2.0 徽章，但当前 Git 树没有 `LICENSE` 文件。为避免未经许可复制代码，本分支先记录上游参考与课程适配内容；需要先核实上游许可，再决定采用正式 fork、获许可复制或独立实现兼容模块。

## 首个试点
先验证“100 以内加减法应用题：读懂问题、识别数量变化和无关信息”。题目为自编样例，不是教材原题。章节名称与具体进度必须以孩子手中教材的封面、版权页和目录为准。
