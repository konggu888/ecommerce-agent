# 儿童学习数据、API 密钥与用量政策

版本：1.0（计划基线）

## 1. Token 使用政策
- 用户明确选择不设置应用层 Token 配额；不设置每日/月度 Token 上限、单题 Token 预算或因费用而削减教学步骤的自动策略。
- 费用按 DeepSeek 账户实际计费规则产生；模型名称、价格和返回的 Token 统计可能变化，以服务商当前文档与账户账单为准。
- 记录服务商可返回的输入/输出 Token、模型、调用用途、时间、耗时、状态和关联学习任务；如果服务商不返回某项，标记为 unavailable，不编造。
- 家长可以查看用量明细；用量展示不改变教学策略。
- 对服务商余额不足、限流、API Key 错误或服务故障要明确提示。系统不得假装调用成功。
- 防止程序缺陷造成无穷技术重试：对相同网络/服务故障采用退避和可恢复状态；这是故障保护，不是教学 Token 限额。不得因普通教学多轮推理而强行截断学习。

## 2. API Key
- 只在服务端环境变量或托管平台 Secret 中存储。
- 只允许后端 provider adapter 读取；前端、题库 YAML、公开配置、客户端 localStorage 和日志均不得包含密钥。
- 提供 `.env.example` 时只能有占位符。
- 不在 GitHub issue、PR、日志、测试快照或对话中粘贴真实密钥。
- 检查构建产物和浏览器网络请求，确保密钥不会到达学生设备。
- 轮换/撤销密钥按 DeepSeek 账户平台流程执行；仓库中只保留配置说明。

## 3. 儿童隐私
- 首期只收集必要的学习记录；避免姓名、生日、学校、精确位置、照片或其他非必要个人资料。
- 学生学习数据默认私密，不用于公开分享或排行榜。
- 明确数据存储位置、保留规则、备份和删除行为。
- 家长可以导出和删除学习数据；删除行为必须真实验证。
- 日志尽量使用内部 ID，屏蔽 API Key 和不必要的儿童作答原文。
- AI 请求仅发送完成当前教学所需的题目、答案/作答和必要学习上下文；不发送身份信息。
- 部署必须使用 HTTPS 和访问控制；生产密钥不能放在仓库或客户端。
- 需要面向公开用户前，重新审核适用的儿童隐私与数据保护要求；首期不默认向公众开放注册。

## 4. 数据生命周期验收
- 创建学习记录 -> 刷新/重新打开后仍存在。
- 导出 -> 文件包含预期记录且不包含密钥。
- 删除 -> 学生记录、关联答题事件和复习任务按定义清除；审计日志不泄露已删除个人数据。
- 错误/失败调用 -> 用量记录状态真实；不保存伪造教学完成记录。
- API Key 扫描 -> 代码、构建产物和日志均无真实密钥。

## 5. 试卷照片与儿童数据的额外要求
- 上传前说明照片用途、处理范围、保留规则和删除方式；仅允许必要的文件类型/大小，拒绝异常文件。
- 原图、OCR 文本、手写答案、老师批改痕迹和评分均属于私密学习数据，必须按学生账户隔离并受访问控制保护。
- 只把当前识别/教学所需内容发送给服务端视觉/OCR/LLM 服务；避免把姓名、学校、班级、学号等不必要身份信息发送给模型，必要时提示裁掉身份信息。
- 提供删除原图、识别结果及其关联学习记录的可验证流程；备份和保留策略要明确，不能声称已彻底删除但实际仍保留可识别副本。
- 图像识别供应商、数据传输范围和可能的第三方处理必须在上线前明确；识别能力不可用时显示失败/待确认，不得静默使用不可靠结果评分。
