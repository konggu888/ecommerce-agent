# 北师大版二年级课程适配计划

版本：1.0（计划基线）

## 1. 教材依据
正式课程映射前，核实孩子实际使用教材的封面、版权页、上下册和目录。不能仅凭“北师大版/2024”推断册次、单元名或教学顺序。家长暂时未提供教材图片时，目录映射保持 `draft`，不得宣称完整覆盖教材。

## 2. 课程数据分层
- 年级/学期/册次：按实际教材版本记录。
- 单元：对应目录中的章节；保留原目录名称和核对状态。
- 知识点：使用稳定 ID；明确前置知识、学习目标、易错点和掌握证据。
- 例题：以自编示例为主；记录分步解法和提示。
- 练习题：区分基础、巩固、易错、换问法、逆向、无关条件、迁移和复测。
- 评估题组：固定版本、覆盖知识点和难度，支持前后测比较。
- 题目来源状态：`draft`、`authored`、`reviewed`、`validated`；自编题不冒充教材原题。

## 3. 每个知识点必须有的字段
- 唯一 ID、教材映射、年级/学期、知识目标、前置知识；
- 概念解释、适龄 worked example、分步提示；
- 常见误区及其可观察证据；
- 标准答案、独立复算步骤、答案类型和单位要求；
- 变式类别、难度、题目验证状态；
- 基础测验/迁移测验/延迟复测关联；
- 内容审校人/日期/变更记录（初期可记录为项目审校状态）。

## 4. 课程覆盖工作流
1. 确认教材版本和目录。
2. 将目录逐项映射为单元与知识点。
3. 标记前置知识关系，检查顺序和依赖循环。
4. 为每个知识点建立学习目标、误区和掌握证据。
5. 编写自编例题和练习，避免整页复制教材。
6. 使用确定性程序复算可校验答案；对自然语言题做人工/独立审校。
7. 生成变式候选题并验证条件完整、答案唯一、年级适配、提示不过度泄题。
8. 通过 schema 和课程测试后才从草稿进入可用题库。
9. 记录覆盖率时按“教材目录项/知识点/已验证题目”分别统计，不用题目总数掩盖空白知识点。

## 5. 首个试点范围
先做 100 以内加减法应用题的读题、数量变化、所求目标、无关条件与逆向问题。当前 YAML 样例只作草稿，必须在确认教材版次和课程 schema 后重新验证。不得把样例当作完整二年级课程。

## 6. 题目质量门槛
每题必须检查：
- 题意清晰，条件充分；
- 题目只问明确目标，答案符合题目要求；
- 算术和中间步骤正确；
- 若有无关条件，确实与所求无关且不会造成合理歧义；
- 难度和用语适合对应年级；
- 提示逐步降低难度但不在第一层直接泄露答案；
- 错误选项/常见错误能对应真实且可解释的误区；
- 不依赖孩子尚未学过的术语或运算；
- 题目来源、校验状态和修订历史清楚。

## 7. 版权边界
不批量复制整本教材、练习册或未经授权的原题。可以根据已核实的教学目标自行创作题目与讲解；教材目录、引用范围和展示方式需遵守适用版权要求。任何来源不明的题目不得标记为已授权。
