# 北师大版二年级课程适配计划

版本：2.0（增加可测量的掌握证据）

## 1. 教材依据
正式课程映射前，核实孩子实际使用教材的封面、版权页、上下册和目录。不能仅凭“北师大版/2024”推断册次、单元名或教学顺序。家长未提供教材信息时，目录映射保持 draft，不得宣称完整覆盖教材。

## 2. 课程数据分层
- 年级/学期/册次：按实际教材版本记录。
- 单元：对应目录章节，保留原目录名称和核对状态。
- 知识点：使用稳定 ID；明确前置知识、目标、易错点、诊断证据和掌握证据。
- 例题：以自编示例为主，记录分步解法和分层提示。
- 练习题：区分基础、巩固、易错、换问法、逆向、无关条件、迁移和复测。
- 评估题组：固定版本、蓝图、知识点权重、难度分布和评分规则，支持前后测比较。
- 题目来源状态：draft、authored、reviewed、validated；自编题不冒充教材原题。

## 3. 每个知识点必须有的字段
唯一 ID、教材映射、年级/学期、知识目标、前置知识、概念解释、适龄例题、分步提示、常见误区及可观察证据、标准答案、独立复算步骤、答案类型、变式类别、难度、题目验证状态、基线/迁移/延迟复测关联、审校状态与修订记录。

## 4. 从课程到掌握证据的工作流
1. 核实教材版本和目录。
2. 将目录映射为单元与知识点。
3. 标记前置知识关系，检查顺序和依赖循环。
4. 为每个知识点建立目标、可观察误区和可验证的掌握标准。
5. 编写自编例题和练习，避免整页复制教材。
6. 使用确定性程序复算答案；自然语言题做独立审校。
7. 生成变式候选题并检查条件完整、答案唯一、年级适配和提示泄题。
8. 通过 schema 和课程测试后才进入可用题库。
9. 用基线、无提示变式、延迟复测观察掌握；错误分类是待验证假设，不能当成孩子的固定标签。
10. 记录覆盖率时分别统计目录项、知识点、已验证题目和测评覆盖率，不用题目总数掩盖空白知识点。

## 5. 首个试点范围
先做 100 以内加减法应用题的读题、数量变化、所求目标、无关条件与逆向问题。当前 YAML 样例只是草稿，必须在确认教材版次和课程 schema 后重新验证，不代表完整二年级课程。

## 6. 题目质量门槛
题意清晰、条件充分、目标明确、算术正确、答案唯一、年级适配、提示逐步降低难度但第一层不泄露答案、误区标签能对应真实错误、不过度使用未学术语、题目来源和校验状态清楚。正式测验题还必须绑定测验蓝图版本，避免重复原题制造虚高。

## 7. 版权边界
不批量复制整本教材、练习册或未经授权的原题。可以根据已核实的教学目标自行创作题目与讲解；来源不明的题目不得标记为已授权。
