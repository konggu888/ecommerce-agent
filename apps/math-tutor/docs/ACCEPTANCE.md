# 首期验收规则

本清单与 `IMPLEMENTATION_PLAN.md` 的 MATH-001–MATH-032 一一配合。某项只有在证据可复查并满足通过条件后，才能标记已验收；计划、代码提交或 CI 通过本身不算产品验收。

## A. 项目复用与许可
- [ ] 核实上游正式许可证/作者授权，并保存可复查来源与对应提交 SHA。
- [ ] 检查实际课程 schema、加载器、提示、答案验证、持久化、模型调用和 UI 代码。
- [ ] 按固定门禁决定直接保留/小幅适配/新建/不复用。
- [ ] 若 OpenMath 不合格，最多再比较两个候选，记录统一评分和选择理由。
- [ ] 在选定项目上实际执行启动和测试命令，记录环境、命令和输出。
- [ ] 授权未确认之前，不复制或再分发上游源码。

## B. 教材与课程
- [ ] 核对孩子实际教材的封面、版权页、上下册和目录。
- [ ] 课程目录逐项映射到单元、知识点和前置依赖。
- [ ] 每题有知识点、目标、条件、所求、标准答案、独立解法、分层提示、误区标签、难度和来源状态。
- [ ] 所有答案独立复算；题意明确、条件完整、答案唯一。
- [ ] AI 生成题先作为草稿，经过 schema、算术、歧义、年级适配和提示泄题检查后才可使用。
- [ ] 不复制整页受版权保护的教材或练习册；自编题不冒充教材原题。
- [ ] 课程 YAML 经选定上游的真实 loader/schema 校验；未运行前不能称兼容。

## C. 教学与错题诊断
- [ ] 第一层提示不直接泄露答案；后续提示逐层降低难度。
- [ ] 支持按需要提供完整解法，但优先引导孩子完成关键思考。
- [ ] 区分审题遗漏、数量关系、运算选择、计算、无关条件、逆向问题、多步顺序和答题表达等错误。
- [ ] 错误诊断带有作答/鉴别题等证据；不把猜测写成确定结论。
- [ ] 同知识点练习覆盖基础、换问法、逆向、无关条件、对比、迁移和纠错题。
- [ ] 原题重做与新题迁移分别统计。
- [ ] 一次答对或提示后答对不直接标记掌握。
- [ ] 复习失败会更新掌握证据并调整复习计划。

## D. DeepSeek、Token 与安全
- [ ] DeepSeek provider adapter 从服务端读取配置；模型 ID 可配置。
- [ ] API Key 不出现在浏览器 bundle、客户端请求、仓库、题库和日志中。
- [ ] 测试成功、格式错误、超时、限流、余额不足和错误 API Key 的处理。
- [ ] 不设置应用层 Token 配额/预算上限；记录可获得的真实用量并展示。
- [ ] 网络故障采用退避与可恢复状态，避免技术重试死循环；正常教学推理不因 Token 用量被截断。
- [ ] 不将失败的 API 请求伪装为成功教学或虚构答案。

## E. 学生、家长和数据
- [ ] 手机浏览器可完成课程选择、答题、分步提示、反馈和继续学习。
- [ ] 刷新/重新打开后学习进度仍然存在。
- [ ] 家长报告显示知识点掌握证据、错误趋势、提示依赖、迁移表现和下一步建议。
- [ ] 掌握状态区分未评估、学习中、初步掌握、掌握和需要复习，并解释依据。
- [ ] 数据存储位置、保留、导出和删除行为清楚且真实可验证。
- [ ] 最少化收集儿童个人信息；部署启用 HTTPS 和访问控制。

## F. 测试、部署与学习效果
- [ ] 自动化测试、静态检查和课程验证结果分别记录。
- [ ] 有可复现的部署步骤和环境变量示例；示例不含真实密钥。
- [ ] 从新环境按文档部署并跑通学生到家长报告的端到端流程。
- [ ] 使用固定版本基线题组与阶段题组，尽量无提示测验。
- [ ] 检查新题迁移和延迟复测，而不只看练习题正确率。
- [ ] 不承诺特定分数提升；数据不可比或不足时明确说明。
- [ ] 每个验收项有结果、证据、日期、提交 SHA；未运行、失败、阻塞、成功状态分开。
