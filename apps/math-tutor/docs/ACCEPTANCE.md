# 首期验收规则（学习闭环版）

本清单与 IMPLEMENTATION_PLAN.md 的 MATH-001–MATH-032 一一对应。只有可复查证据满足条件后才能标记已验收。计划、提交、部署成功、AI 自评或 CI 绿灯本身均不等于产品验收。

## A. 选型与许可
- [ ] 正式许可证/作者授权有可复查来源、日期和上游 commit SHA。
- [ ] 实际检查课程 schema、答题验证、提示、进度持久化、模型调用、手机 UI 和测试。
- [ ] 最多比较 3 个候选，记录统一标准和选择理由。
- [ ] 选定项目的启动/测试实际运行；失败结果也保留。
- [ ] 许可未确认前不复制或再分发上游代码。

## B. 教材与题目可信度
- [ ] 核实实际教材封面、版次、上下册、目录和当前进度。
- [ ] 教材目录映射到单元、知识点、前置依赖和目标；未核对项标 draft。
- [ ] 每题具备明确目标、条件、答案、独立解法、分层提示、误区标签、题型和来源状态。
- [ ] 题目通过 schema、算术、条件完整性、答案唯一性、年级适配及提示泄题检查。
- [ ] AI 生成题经独立校验/必要人工审查后才进入练习或正式测验。
- [ ] 不批量复制未授权教材内容；自编题不冒充教材原题。

## C. 诊断—教学—验证闭环
- [ ] 每次错误保留实际作答证据，错误标签可追溯到答案/解释/鉴别题。
- [ ] 不确定时标 unknown，不把 AI 推测当事实。
- [ ] 重复或模糊错误可触发鉴别题，检查审题、数量关系、运算、计算及前置知识。
- [ ] 系统记录教学策略、选择理由、预期改变的困难和后续验证结果。
- [ ] 后续独立表现未改善时，系统会调整策略或检查前置知识，而不是无限重复相同提示。
- [ ] 教学后的不同表述变式题尽量无提示；不能只重复刚讲过的题。
- [ ] 系统逐渐减少不必要提示，但不会为了制造独立率而拒绝合理求助。

## D. 提示、重做和掌握度
- [ ] 每题每回合最多 3 次主动提示，提示逐层深入且不自动弹出。
- [ ] 看过解法、答错或用过提示的题进入重做队列，间隔 3–5 道其他题或放到下一次学习。
- [ ] 重做时不自动展示旧提示/解法，先独立作答。
- [ ] 首次表现、提示后表现、原题重做、迁移、无提示测验和延迟复测分开统计。
- [ ] 单次正确、提示后正确或重复原题正确不能独立证明掌握。
- [ ] 掌握状态解释样本数、独立表现、迁移和延迟证据；证据不足时不伪造确定性。
- [ ] 复测失败会缩短复习间隔并重新诊断。

## E. 测量与学习效果
- [ ] 每单元有固定蓝图基线、不同题目的结束平行测验和延迟复测。
- [ ] 期中/期末有覆盖已学单元的累积测验，题组版本与评分规则可追溯。
- [ ] 测验尽量无提示，记录题目版本、知识点权重、难度、条件和样本数。
- [ ] 报告分开显示练习成绩、无提示测验、迁移题、延迟复测和学校考试成绩。
- [ ] 前后测题目不同但蓝图尽量可比；记录测量误差和限制。
- [ ] 未提升时系统实际执行诊断、补弱、调整策略和复测，而不只是给出建议文字。
- [ ] 不保证特定提分；应用测验提升不自动等于学校考试提升。
- [ ] 首期效果报告如实记录成功、未提升、数据不足和未运行项。

## F. DeepSeek、Token、安全和隐私
- [ ] DeepSeek adapter 服务端读取配置，模型 ID 可配置。
- [ ] API Key 不出现在前端 bundle、浏览器请求、题库、Git、客户端日志。
- [ ] 成功、格式错误、超时、限流、余额不足和错误 key 状态有测试。
- [ ] 不设应用层 Token 配额；用量以服务商返回为准，未提供则标 unavailable。
- [ ] 故障重试有退避和恢复策略，不无限重放；不伪装失败调用为成功。
- [ ] 最少收集儿童信息；数据保留、导出、删除和访问控制真实可验证。

## G. 学生、家长、部署和端到端
- [ ] 手机浏览器完成基线、练习、提示、诊断、教学调整、无提示变式、重做和复习。
- [ ] 刷新/重开后答题事件、复习队列、测验版本和教学状态仍存在。
- [ ] 家长报告解释为什么系统认为会/不会，并显示策略调整记录和结果。
- [ ] 自动化测试、静态检查、课程验证、测验逻辑测试分别记录。
- [ ] 从新环境部署后跑通基线到家长报告的完整链路。
- [ ] 每项证据记录日期、提交 SHA、命令/步骤、结果和状态；未运行/失败/阻塞/成功分开。

## H. v2.1 强制验收：有限时间内的真实掌握与试卷拍照

### 学习时间和任务效率
- [ ] 家长可设置每日学习时间上限；默认建议约 10 分钟但可调整，系统不要求学满。
- [ ] 达到上限后不启动新任务；当前状态可安全结束，未完成任务可恢复并顺延。
- [ ] 任务排序使用掌握证据、错误复现、前置依赖、课程重点与复测到期状态，并保存可解释理由。
- [ ] 稳定掌握的知识点减少练习频率；掌握状态不足时不凭猜测跳过必要诊断。
- [ ] 每道题有诊断/教学/独立检查/迁移/复习/测评目的，不能以刷题数量作为成功标准。
- [ ] 策略无效时系统真实切换策略或检查前置知识，并记录调整前后证据。

### 试卷照片与状态分流
- [ ] 可上传单页/多页试卷照片，进行图像质量检查、结构化识别与题号关联。
- [ ] 明确覆盖空白试卷、孩子已作答未批改、老师已批改三种状态。
- [ ] 空白卷先独立作答，不提前展示答案；已作答未批改卷保留首次作答；已批改卷保留老师批改痕迹与原始分数来源。
- [ ] 模糊题干、数字、符号、图表、手写答案、批改标记或分值的低置信度字段必须请求确认。
- [ ] 识别不确定或识别失败时保存可恢复状态，不编造题目、答案、分数或诊断。
- [ ] 图片题映射到课程知识点并进入共用诊断—教学—独立验证—错题重做—延迟复测闭环。
- [ ] 老师原始分数、系统确定性评分、AI 估计分数分开记录和显示。
- [ ] 照片、识别结果、手写答案、批改痕迹有访问控制、保留说明、导出和删除测试。

### 必须通过的行为回归测试
- [ ] 时间上限达到后不会再开始下一道题/新任务。
- [ ] 稳定掌握的知识点排序优先级下降，未掌握的高价值前置知识能提升优先级。
- [ ] 空白卷不会在首次作答前泄露答案。
- [ ] OCR 错误/低置信度不会直接改变分数、错误标签或掌握状态。
- [ ] 老师批改分数不会覆盖系统测评；AI 估分不会伪装成老师评分。
- [ ] 同一照片原题的重做不会计为新题迁移证据。
- [ ] 教学策略无效后下一步确实变化，连续失败不无限重复同一策略。
- [ ] 端到端至少运行一次“试卷上传→确认→辅导→独立验证→延迟复测→家长报告”链路。

## H. v2.1 强制验收：有限时间内的真实掌握与试卷拍照

### 时间效率
- [ ] 家长可设置每日时间上限；默认建议约 10 分钟但可调整，系统不要求学满。
- [ ] 到达上限后不启动新任务；当前交互安全结束，未完成项可恢复并顺延。
- [ ] 排序使用掌握证据、错误复现、前置依赖、课程重点与复测到期状态，并保存理由。
- [ ] 稳定掌握知识点减少练习频率；每题有诊断/教学/独立检查/迁移/复习/测评目的。
- [ ] 教学无效后实际切换策略或检查前置知识并记录前后证据。

### 试卷照片
- [ ] 支持单页/多页照片、图像质量检查、题号关联与结构化识别。
- [ ] 覆盖空白、孩子已作答未批改、老师已批改三种状态。
- [ ] 空白卷先独立作答；已作答卷保留首次表现；已批改卷保留教师批改与原始分数来源。
- [ ] 题干/数字/符号/图表/手写答案/批改标记/分值低置信度时必须请求确认。
- [ ] 识别失败可恢复，不编造题目、答案、分数或诊断。
- [ ] 照片题映射知识点并进入共享教学、重做和延迟复测闭环。
- [ ] 教师原始分数、系统确定性评分、AI 估分分开存储和展示。
- [ ] 照片和识别结果具备访问控制、保留说明、导出与删除测试。

- [ ] 策略无效后下一步确实变化，不无限重复相同策略。
- [ ] 至少实际运行一次“上传→确认→辅导→独立验证→延迟复测→家长报告”端到端链路。


## 2026-10-19 中国小学二年级儿童界面体验验收
- 简体中文原生表达；题目语气、单位、符号与生活情境符合已核对的教材和年级。
- 手机端字号、行距、触控区域、页面层级与对比度通过真实设备或视口测试；核心流程不依赖悬停操作。
- 视觉温暖、清晰、灵动、耐看；动效适度且可关闭，不使用闪烁/过度刺激效果。
- 可选普通话朗读和安静模式；答错反馈不羞辱孩子，趣味奖励不依赖强制签到、公开排名或单纯刷题数量。
- 可视化（数轴、分组、图形/操作演示等）必须帮助解释数学概念，不能泄露空白试卷答案或影响测验公平性。
- 儿童体验由明确的手机端检查步骤和可复现测试留证；只写设计原则不算验收。


## I. 自主选择、跨单元累计复习与数学正确性（首期强制）
- [ ] 自主练习可以只选择一个单元，且题目范围不越界。
- [ ] 可以组合任意多个已学单元、选择全部已学单元累计复习，并调整当前单元与旧单元的比例。
- [ ] 系统明确区分多单元混合练习与单题跨知识点综合应用。
- [ ] 可选择知识点、难度和练习类型；单元选择与试卷照片错题/课程知识点档案共享。
- [ ] 自主练习与老师作业分开；老师作业范围不被擅自扩大，额外补弱练习有清晰标记。
- [ ] 孩子可以暂停、跳过、返回旧单元、重学或探索尚未正式学习的单元；AI 推荐可以接受或修改，不会仅因前置知识不足而强制锁定单元。
- [ ] 若系统建议加入未选择的旧单元，必须先说明理由并征得孩子选择，不得静默混入。
- [ ] 跨单元题目记录单元/知识点/前置依赖/练习目的/难度/版本；不得要求使用未学知识作为隐藏前提。
- [ ] 系统能够区分当前知识困难与前置知识困难；证据不足时标记 unknown，不因单次错误给孩子贴稳定标签。
- [ ] 数学题目经过适用的独立答案、算术、条件完整性、歧义和评分校验；AI 自检不能单独作为正确性证据。
- [ ] 题目或图片识别不确定时可确认、修正、跳过或恢复；不静默猜测，不虚构分数，不把系统题目错误归因于孩子。
- [ ] 可暂停/结束学习；不通过强制签到、公开排名或刷题量制造压力。


## J. AI 老师声音、形象、数学黑板与可配置积分奖励（首期强制）

### 声音与 AI 老师形象
- [ ] 有清晰、适合中国小学二年级孩子的 AI 数学老师形象；讲解、倾听、思考和鼓励状态清晰可辨。
- [ ] 普通话讲解音频与同步字幕一致；可暂停、重播、调音量和关闭声音。
- [ ] 鼓励反馈具体、温和，不只奖励答对，也肯定思考、尝试和修正；错误反馈不羞辱孩子。
- [ ] 音频不可用、浏览器阻止自动播放或启用安静模式时，完整文字内容仍可使用；不出现与音频不一致的假说话状态。
- [ ] 手机端实测音频播放、字幕、静音、暂停/重播和语音失败回退；第三方声音/人物素材许可可追溯。

### 黑板讲解
- [ ] 有实际可用的数学黑板/板书区域，不只是装饰背景。
- [ ] 黑板能逐步显示当前题目所需算式、图形、数轴、数量分组或步骤，并支持暂停、前后步骤和重播。
- [ ] 黑板上的数字、算式、单位、图形和答案与已确认题目一致，经过适用的数学校验。
- [ ] 空白试卷首次作答和无提示测验期间不通过 AI 老师、黑板、音频或动画泄露答案/提示。

### 积分与可配置奖励兑换
- [ ] 家长可以自定义奖励名称、描述、积分门槛，随时添加、编辑和停用；不存在固定的 10/20 分奖励表。
- [ ] 积分规则可解释且不单纯鼓励刷题；答错、求助、暂停或休息不扣分。
- [ ] 孩子能查看余额、积分获得原因、奖励门槛，并在兑换前看到奖励与扣分信息、明确确认。
- [ ] 兑换后从可用余额扣除积分，但获得/兑换历史流水和学习记录都保留；旧兑换记录不因奖励目录修改而改变。
- [ ] 余额不足不能兑换；重复点击/重试不会重复扣分或重复兑换；失败兑换不会出现无流水的扣分。
- [ ] 刷新/重开后余额、积分流水、奖励目录与兑换状态仍然正确。
- [ ] 积分与知识掌握度/测验成绩分开；积分不能作为掌握证据，也不能以公开排行榜或强制签到施压。



### AI 老师形象验收补充
- [ ] 形象采用原创的高质量 3D/半写实或写实插画方向，具备可信、亲和、适合中国小学二年级的教师气质；不能只是默认幼儿卡通模板。
- [ ] 设计记录说明参考的是豆包、学而思、作业帮等产品的抽象视觉方向（逼真、亲和、自然），未复制其具体角色、商标、专有界面、美术资产或声音。
- [ ] 对至少 2 种原创视觉方案进行儿童适配、可信度、移动端性能和素材许可评估；实际手机端检查清晰度、加载和说话状态。
- [ ] 老师说话状态、真实音频播放和字幕同步；没有音频时不能假装正在说话。
