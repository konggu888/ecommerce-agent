# 首期验收规则

## 教材与题目
- [ ] 以孩子手中北师大版课本封面、版权页、目录核定版次和上下册。
- [ ] 课程知识点覆盖范围与教材目录逐项对应。
- [ ] 每题有标准答案、解题步骤、知识点、易错类型和分层提示。
- [ ] 所有答案独立复算；题意明确、条件完整、答案唯一。
- [ ] 不直接复制受版权保护的整页教材或原题；以自编题覆盖相同知识目标。

## 引导与陷阱识别
- [ ] 第一层提示不直接泄露答案。
- [ ] 第二层提示缩小思考范围，但仍让孩子完成推理。
- [ ] 区分审题遗漏、数量关系理解错误、计算错误、无关条件误用、逆向问题误判和答非所问。
- [ ] 不把所有题目都设计成陷阱；基础练习与易错专项分开。

## 举一反三与复习
- [ ] 同知识点练习至少覆盖基础题、换问法、干扰条件和迁移题。
- [ ] 原题重做与新题迁移分开统计。
- [ ] 不能因为一次答对或记住原题就标记掌握。
- [ ] 根据错误情况安排间隔复习；复习结果更新掌握度。

## 学习数据与家长查看
- [ ] 按学生保存答题、错误类型、提示使用情况和复做结果。
- [ ] 家长能查看薄弱知识点和最近学习趋势。
- [ ] 学习记录保存在本地或明确告知数据去向。
- [ ] 支持导出或清除学习记录。

## 工程验收
- [ ] 上游许可证/作者授权核查完成后，才迁移上游代码。
- [ ] 新增课程通过上游课程 schema 校验。
- [ ] 相关自动化测试通过；没有运行的测试明确标记为未运行。
- [ ] 不把 CI 通过等同于完整产品验收。
