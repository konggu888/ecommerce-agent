# 产品需求规格：北师大版二年级 AI 数学学习系统

版本：2.1（有限时间内的真实掌握与试卷辅导）
状态：计划基线 2.2；自研项目，不依赖第三方上游选型门禁。
项目位置：apps/math-tutor/；与 apps/ad-studio-desktop/ 完全隔离。

## 1. 产品使命
交付一个孩子可通过手机浏览器使用的中文响应式数学学习网站。它不是只会解题的聊天机器人，而是能够识别知识缺口、验证错误原因、选择教学策略、逐渐培养独立性，并用可比测评验证学习变化的闭环系统。
最高目标是帮助孩子真正掌握其实际使用的北师大版小学数学二年级教材，并通过独立测验、迁移题、延迟复测及学校成绩对照，诚实评估是否进步。不承诺未经测量的分数提升。

## 2. 系统必须回答的七个问题
1. 孩子目前独立掌握什么？证据来自哪些题、何时测得？
2. 错误更可能源自审题、概念/数量关系、运算选择、计算、步骤或表达中的哪一类？诊断依据和不确定性是什么？
3. 系统选择了什么教学方式，为什么它适合当前证据？
4. 教学后孩子能否在没有提示的情况下独立完成不同题目？
5. 经过一段时间，孩子是否仍然记得，能否迁移到新题？
6. 单元、期中、期末的可比测验是否显示真实变化？
7. 如果没有进步，系统采取了什么调整，复测结果如何？
如果系统只能回答今天做对了几道题，则不满足核心目标。

## 3. 核心成功标准
- 每个知识点有掌握状态、样本数、最近证据、独立答题/提示/迁移/延迟复测情况及判定理由。
- 错误诊断是可检验假设；必要时用鉴别题区分原因，证据不足标 unknown。
- 教学策略依据诊断选择；后续表现决定保留或调整策略。
- 每题每回合作答最多 3 次主动提示；提示后答对不计独立掌握。
- 答错、用过提示或看过解法的原题进入重做队列；重做时不自动展示旧提示。
- 原题重做、同型变式、迁移题、无提示测验和延迟复测分开记录。
- 系统逐步培养独立性，不以强行限制合理求助来制造独立。
- 每单元具有基线、结束平行测验和延迟复测；期中/期末具有覆盖已学知识的累积测验。
- 家长报告显示真实成绩变化、测量条件、题组版本、薄弱项、提示依赖、迁移和延迟保持。
- 未提升时系统诊断、补弱、检查前置知识并复测；不伪造成功。
- 所有能力有测试或人工验收证据；上线、AI 自评、练习正确率和 CI 绿灯不等于学习有效。

## 4. 学生和家长流程
学生：首次基线测评 → 逐步学习 → 独立作答 → 必要时主动请求提示 → 错误诊断/教学 → 独立变式题 → 原题间隔重做 → 延迟复测。
家长：查看教材进度和知识点证据 → 查看测评变化与不确定性 → 查看提示依赖 → 查看错误模式和前置缺口 → 查看已尝试的教学策略及结果 → 查看下一步补弱计划。报告区分事实、AI 推测和测量限制。

## 5. 教学闭环
每次显著错误应形成可追踪链路：作答证据 → 错误假设及置信度 → 必要的鉴别题 → 教学策略及选择原因 → 学生练习 → 无提示变式验证 → 延迟复测 → 保留/调整策略。
证据不足时继续收集证据，不把猜测写成事实。连续失败时检查前置知识或换教学方式，不机械重复同一提示。

## 6. 测量和学习效果
- 单元：基线测验、学习与补弱、不同题目的结束平行测验、延迟复测。
- 期中/期末：覆盖对应阶段已学单元的累积测验，并按固定蓝图分析。
- 测验尽量无提示，记录题组版本、知识点权重、难度、评分规则、作答条件和样本数。
- 分别报告练习正确率、无提示测验、原题重做、迁移题、延迟复测和学校正式考试成绩；不可合并成误导性分数。
- 前后题组尽量可比但不重复原题；记录测量限制。分数变化可能受题目难度、练习效应等影响，不能夸大因果。
- 若没有提升：分析错误和前置知识、调整策略、补弱、再测；如仍未提升，如实报告。

## 7. AI、模型和 Token
- 首选用户已有 DeepSeek API；模型 ID/base URL 可配置。
- 不要求本地模型，不设置应用层 Token 配额、日/月上限或单题预算；按服务商实际用量计费。
- 允许为充分诊断、教学调整、题目生成与复核进行必要多轮调用，不因 Token 量主动截断正常教学。
- 记录服务商返回的用量、模型、用途、时间、状态和耗时；未返回的用量标记 unavailable，不编造。
- API Key 只存服务端。技术故障重试采用退避与可恢复状态，防止软件死循环；这不等于限制正常教学轮次。
- AI 输出的题目、诊断和测量分析都需通过适用的独立验证；AI 不可自我认证学习效果。

## 8. 首期必须交付
手机友好网站；可配置 DeepSeek 后端；课程和题目验证；提示与错题队列；可检验诊断和教学调整；独立性渐进与掌握证据；单元/期中/期末测量；家长报告；持久化、导出和删除；部署、安全、自动化测试和可复现验收。

## 9. 明确不在首期范围
不训练基础模型；不做原生 Android/iOS；不接学校系统、班级、社交、排行榜、广告或订阅；不批量复制整本教材；不保证特定提分；不把 AI 自评当证据；不修改电商桌面应用；不因开发中临时想到的功能扩大范围。额外方向放入后续候选，只有批准新计划版本后才能纳入。

## 10. 自研原则与第三方许可
从头开发自有应用。开源项目可以全网研究以借鉴框架、交互、OCR/视觉方案、教学设计与测试经验；不要求先选定或运行某个上游才能开发，也不复制未经核实许可的候选源码。第三方依赖、字体、图片、音效、教材内容和模型分别核查许可与使用条件。

## v2.1 强制实现与验收约束

## 11. 时间受限的自适应学习与试卷入口（首期强制范围）

### 每日时间和任务选择
- 家长可设置每日学习时间上限；建议默认值约 10 分钟，可调整且可设为更短。它是上限，不是必须完成的最低时长。
- 学习编排器根据掌握证据、近期错误、前置知识、当前课程重点、测评结果和复习到期情况排序。不得单纯按固定教材顺序或待做题数量灌题。
- 时间接近上限时完成当前必要交互后结束，不启动新题组；未完成任务顺延且不产生惩罚性提醒。
- 稳定掌握的知识点减少练习频率，仅安排必要抽查；证据不足时标记待确认，不能为了省时间直接跳过关键诊断。
- 每道题必须有明确目的标签：diagnose、teach、independent_check、transfer、review 或 assessment。无明确目的的题不应进入当日任务。
- 不能用游戏化签到、排行榜或强制打卡增加负担；不以刷题数量替代掌握。

### 试卷拍照入口
- 学生/家长可上传单张、多张或多页试卷照片，并选择/确认状态：空白试卷、孩子已作答但未批改、老师已批改。自动识别只能提供建议，不能在不确定时静默定类。
- 系统检查图像清晰度、旋转、裁切和页面完整性；无法可靠识别的题目/符号/手写答案/批改标记要标记不确定并请求确认。
- 结构化保存题号、题干、数学符号、图表/几何信息、学生答案与过程、老师批改痕迹、分值、识别置信度、人工确认状态和来源图片关联。
- 空白卷先独立作答，不预先显示答案；已作答未批改卷保留原始作答并按独立证据分析；已批改卷保留老师批改和分数作为独立来源，优先分析错题。
- 图片题必须映射到课程知识点，并与教材学习共用同一学生档案、诊断—教学—无提示验证—错题重做—延迟复测闭环。
- 老师实际评分、系统自动评分、系统估计分数必须分开显示；无法确认的老师批改痕迹不得自动计入确定分数。
- 图片识别/OCR/手写数学/图形理解能力必须经过候选技术实际评估；不能假设单一 LLM 对所有图片可靠，也不能在上游许可门禁未通过时开始复制代码。
- 原图与识别数据遵循最少收集、私密访问、明确保留、可导出/删除原则；不得将儿童身份信息作为不必要的模型输入。

### 必须实现的验收结果
至少通过：三种试卷状态的分流测试；识别置信度不足时要求确认；图片错误不会静默变成错误教学结论；空白卷不会提前泄露答案；老师分数与系统分数隔离；图片题进入相同错题与延迟复测队列；每日时间上限阻止启动新任务；稳定掌握知识点会减少练习；策略无效时系统状态和后续动作实际改变。


## 2026-10-19 产品方向调整：自研实现，不以第三方框架为前置门禁
用户已明确决定从头开发本产品。公开开源项目只用于全网调研和设计借鉴；不得因为某个参考项目缺功能、技术栈不匹配或许可证不清楚，就删除、缩减本项目已经确定的任何功能。默认不复制候选项目源码；借鉴其通用思路、交互模式和可验证经验，并遵守第三方代码、字体、图片、音效、教材内容及模型各自的许可。

### 中国小学二年级儿童的界面与体验要求
- 简体中文原生表达，贴近中国小学课堂和家庭辅导习惯；题干、单位、标点、数学符号、人民币/日历/时间/长度等生活情境以实际课程与年级为准。
- 视觉目标是“温暖、清晰、灵动、耐看”，不是幼儿园化或堆满动画：圆润卡片、明确层级、柔和但有足够对比的色彩、适度插画/角色、轻量动效和有意义的声音反馈；避免闪烁、过度刺激、连续签到压力、公开排名和羞辱性错题反馈。
- 学生端优先单手手机操作、可读大字、明确触控区域、少量每屏任务；支持语音朗读开关和安静模式。家长端呈现证据、设置与解释，不把复杂分析压给孩子。
- 趣味性服务于数学理解：可视化数量、分组、数轴、图形、操作演示、探索任务和小成就；奖励策略、思考过程与进步，不以刷题数量、速度或连续打卡替代掌握。
- 设计需通过真实手机尺寸、低识字负担、色彩对比、减少认知负荷和儿童可理解性检查；不以审美口号代替可用性验收。

### 不得删减的首期能力
原产品规格与 MATH-001–MATH-032 中已确定的功能全部保留，包括试卷拍照/多页上传及三种状态分流、OCR/手写/图表/教师批改识别和人工确认、DeepSeek 可配置调用、每日学习时间上限、证据驱动任务编排、诊断与策略切换、三次分层提示、错题重做、掌握度、迁移/间隔复习/延迟复测、单元/期中/期末测量、家长报告、儿童隐私、数据导出/删除、故障恢复和自动化/手机端验收。技术实现可以分阶段交付，但不能把强制功能降级为“以后再做”。
