# 产品需求规格：北师大版二年级 AI 数学学习系统

版本：2.0（以真实掌握与可验证进步为中心）
状态：计划基线；项目选型和许可门禁通过前不进入应用实现。
项目位置：apps/math-tutor/；与 apps/ad-studio-desktop/ 完全隔离。

## 1. 产品使命
交付一个孩子可通过手机浏览器使用的中文响应式数学学习网站。它不是只会解题的聊天机器人，而是能够识别知识缺口、验证错误原因、选择教学策略、逐渐培养独立性，并用可比测评验证学习变化的闭环系统。
最高目标是帮助孩子真正掌握其实际使用的北师大版小学数学二年级教材，并通过独立测验、迁移题、延迟复测及学校成绩对照，诚实评估是否进步。不承诺未经测量的分数提升。

## 2. 系统必须回答的七个问题
1. 孩子目前独立掌握什么？证据来自哪些题、何时测得？
2. 错误更可能源自审题、概念/数量关系、运算选择、计算、步骤或表达中的哪一类？诊断依据和不确定性是什么？
3. 系统选择了什么教学方式，为什么它适合当前证据？
4. 教学后孩子能否在没有提示的情况下独立完成不同题目？
5. 经过一段时间，孩子是否仍然记得，能否迁移到新题？
6. 单元、期中、期末的可比测验是否显示真实变化？
7. 如果没有进步，系统采取了什么调整，复测结果如何？
如果系统只能回答今天做对了几道题，则不满足核心目标。

## 3. 核心成功标准
- 每个知识点有掌握状态、样本数、最近证据、独立答题/提示/迁移/延迟复测情况及判定理由。
- 错误诊断是可检验假设；必要时用鉴别题区分原因，证据不足标 unknown。
- 教学策略依据诊断选择；后续表现决定保留或调整策略。
- 每题每回合作答最多 3 次主动提示；提示后答对不计独立掌握。
- 答错、用过提示或看过解法的原题进入重做队列；重做时不自动展示旧提示。
- 原题重做、同型变式、迁移题、无提示测验和延迟复测分开记录。
- 系统逐步培养独立性，不以强行限制合理求助来制造独立。
- 每单元具有基线、结束平行测验和延迟复测；期中/期末具有覆盖已学知识的累积测验。
- 家长报告显示真实成绩变化、测量条件、题组版本、薄弱项、提示依赖、迁移和延迟保持。
- 未提升时系统诊断、补弱、检查前置知识并复测；不伪造成功。
- 所有能力有测试或人工验收证据；上线、AI 自评、练习正确率和 CI 绿灯不等于学习有效。

## 4. 学生和家长流程
学生：首次基线测评 → 逐步学习 → 独立作答 → 必要时主动请求提示 → 错误诊断/教学 → 独立变式题 → 原题间隔重做 → 延迟复测。
家长：查看教材进度和知识点证据 → 查看测评变化与不确定性 → 查看提示依赖 → 查看错误模式和前置缺口 → 查看已尝试的教学策略及结果 → 查看下一步补弱计划。报告区分事实、AI 推测和测量限制。

## 5. 教学闭环
每次显著错误应形成可追踪链路：作答证据 → 错误假设及置信度 → 必要的鉴别题 → 教学策略及选择原因 → 学生练习 → 无提示变式验证 → 延迟复测 → 保留/调整策略。
证据不足时继续收集证据，不把猜测写成事实。连续失败时检查前置知识或换教学方式，不机械重复同一提示。

## 6. 测量和学习效果
- 单元：基线测验、学习与补弱、不同题目的结束平行测验、延迟复测。
- 期中/期末：覆盖对应阶段已学单元的累积测验，并按固定蓝图分析。
- 测验尽量无提示，记录题组版本、知识点权重、难度、评分规则、作答条件和样本数。
- 分别报告练习正确率、无提示测验、原题重做、迁移题、延迟复测和学校正式考试成绩；不可合并成误导性分数。
- 前后题组尽量可比但不重复原题；记录测量限制。分数变化可能受题目难度、练习效应等影响，不能夸大因果。
- 若没有提升：分析错误和前置知识、调整策略、补弱、再测；如仍未提升，如实报告。

## 7. AI、模型和 Token
- 首选用户已有 DeepSeek API；模型 ID/base URL 可配置。
- 不要求本地模型，不设置应用层 Token 配额、日/月上限或单题预算；按服务商实际用量计费。
- 允许为充分诊断、教学调整、题目生成与复核进行必要多轮调用，不因 Token 量主动截断正常教学。
- 记录服务商返回的用量、模型、用途、时间、状态和耗时；未返回的用量标记 unavailable，不编造。
- API Key 只存服务端。技术故障重试采用退避与可恢复状态，防止软件死循环；这不等于限制正常教学轮次。
- AI 输出的题目、诊断和测量分析都需通过适用的独立验证；AI 不可自我认证学习效果。

## 8. 首期必须交付
手机友好网站；可配置 DeepSeek 后端；课程和题目验证；提示与错题队列；可检验诊断和教学调整；独立性渐进与掌握证据；单元/期中/期末测量；家长报告；持久化、导出和删除；部署、安全、自动化测试和可复现验收。

## 9. 明确不在首期范围
不训练基础模型；不做原生 Android/iOS；不接学校系统、班级、社交、排行榜、广告或订阅；不批量复制整本教材；不保证特定提分；不把 AI 自评当证据；不修改电商桌面应用；不因开发中临时想到的功能扩大范围。额外方向放入后续候选，只有批准新计划版本后才能纳入。

## 10. 前置门禁
核实开源候选许可、真实运行能力、课程 schema、模型适配、移动端可用性和测试。OpenMath 是第一候选但不是预设通过；许可未确认前不复制源码。最多评估三个候选。
