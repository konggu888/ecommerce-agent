# AI 商品广告工厂（桌面版）帮助文档

> 本文是项目的长期功能说明书。以后每增加、修改或修复一项用户可见功能，都必须同步更新本文件的“功能总表”和“更新记录”。

## 1. 产品定位
AI 商品广告工厂是 Windows 本地桌面软件：
- 本地计算设备负责能高效完成的编排、素材管理、视频加工、FFmpeg 后处理和最终合成；系统自动检测硬件能力。
- 云端只负责本地难以生成的高质量素材/视频任务。
- 本地资产库优先复用；没有合适素材时才允许自动生成。
- 生成后的可复用素材进入本地永久资产库。
- 项目工程、成片和资产库分开储存。
- 云端成本在真正调用前预估并展示。

## 2. 完整工作流
商品链接 → 商品资料采集 → AI商品理解 → 卖点提炼 → 人群与痛点 → 广告策略 → 广告强度 → 视频形式 → 剧本 → 分镜 → 每镜头资产需求 → 项目级成本预估 → 用户预算确认 → 本地资产匹配 → 缺失资产按需云端生成 → 资产永久入库 → 云端镜头生成 → 本地硬件/FFmpeg后处理 → 字幕/音频/BGM → 最终拼接。

## 3. 创建广告项目与预算
用户可以为每个项目输入自己的预算，例如 ¥3、¥5、¥10、¥50。

创建前显示：
- 视频生成费用
- 演员生成费用
- 场景生成费用
- 商品素材生成费用
- 本地处理费用
- 总费用

如果总费用超过本次预算：
- 明确显示超预算。
- 明确询问是否继续。
- 不自动换模型。
- 不自动降低质量。
- 不自动减少镜头。
- 不自动改变广告方案。

用户取消：
- 不保存新项目。
- 不开始后续云端素材生成。
- 不产生后续云端素材调用费用。

## 4. 成本计算
- 视频成本按计划镜头数 × 当前视频Provider价格。
- 演员/场景/商品素材成本按本地缺失的唯一资产需求计算。
- 同一资产需求跨多个镜头只计一次。
- 价格来自本机Provider配置；占位价格不能冒充供应商正式报价。
- 实际生成后记录实际发生费用。

## 5. 本地资产库
资产类型包括演员、场景、商品素材、BGM。

匹配原则：
**本地优先 → 可复用直接复用 → 可加工则本地加工 → 没有合适素材才自动生成。**

AI生成的新资产：
- 自动保存到本地资产库。
- 获得稳定资产ID。
- 后续项目优先复用。
- 避免相同演员/场景反复付费生成。

## 6. 资产库可自定义硬盘
为了避免系统盘爆满，资产库支持独立硬盘目录。

例如：
- D:\AI广告素材库
- E:\电商资产库
- F:\广告工厂\Assets

桌面端入口：
**💾 资产库位置 → 选择硬盘目录 → 保存并切换**

资产库与项目工程目录分离。切换位置不会自动删除旧资产，也不会偷偷搬迁旧资产。

## 7. 多模型AI创意引擎
当前独立路由：
- 商品理解
- 卖点提炼
- 人群与痛点
- 广告策略
- 广告强度判断
- 视频形式判断
- 剧本
- 分镜
- 素材选择

默认GPT；不同功能可以使用不同模型，也支持本地模型。

### 多创意方案
同一个商品可以一次生成 1 或 3 个彼此明显不同的广告方案。
- 每个方案仍经过独立的商品理解、卖点、人群、策略、强度、视频形式、剧本、分镜、素材选择流程。
- 系统会把前一个方案的打法传给后续方案作为“避免重复”的约束，而不是固定把某个行业硬套成某一种视频。
- 用户可以在同一个项目中切换方案，再分别生成镜头和成片。
- 方案数量为 3 时，系统目标是测试三个不同的广告机制，而不是只改标题或换几句文案。
- 云端视频/素材成本按当前选中的方案单独预估；切换方案后需要重新确认当前方案成本。

## 8. 本地硬件能力 / FFmpeg
## 8.1 本地实拍视频 AI 自动剪辑

桌面端现在有独立的“用户拍摄素材”工作流：
**商品资料 + 用户实拍视频文件夹 → 关键帧视觉分析 → 卖点/商品/人物/场景/重复/遮挡/糊片等判断 → AI剪辑导演 → 本地FFmpeg裁剪 → 后处理 → 成片**。

实拍分析不再只看文件名、时长和分辨率。系统会从每个可解析视频均匀抽取少量低分辨率关键帧；启用“支持图片/视频帧分析”的模型后，关键帧会作为视觉输入交给“素材剪辑导演”。视觉分析结果保存到项目的 `creative_plan.footage_visual_analysis`，后续剪辑导演再根据这些结果决定具体起止时间。

模型设置新增：
- **支持图片/视频帧分析**：实拍视觉分析必须打开。
- 默认 GPT 模型会预设开启；自定义本地/云端模型必须确认自身接口支持图片输入。

注意：当前分析粒度是“关键帧视觉分析”，不是把整段视频作为原生视频文件直接交给模型。口播逐字稿、逐帧动作识别、自动人声去废话仍需后续接入专门的视频理解/转写能力。

已接入：
- GPU检测
- FFmpeg检测
- NVENC硬件编码
- 画幅适配
- 裁切
- 缩放
- AI构图坐标执行
- 速度调整
- 转场
- 字幕烧录
- 人声/BGM混音
- 最终视频拼接
- 镜头版本化

支持9:16、1:1、16:9。

## 9. 镜头版本化
每个镜头独立生成和重新生成，例如：
- shot-01/v1
- shot-03/v2
- shot-04/v1

修改一个镜头时不要求重新生成其他镜头。

## 10. 云端视频生成
通用REST Provider可配置：
- 供应商名称
- Endpoint
- 模型ID
- API Key
- 查询Endpoint
- 轮询间隔
- 每镜头价格

不同供应商协议不同，通用适配器不能假装兼容所有供应商。

## 11. 自动素材生成
演员、场景、商品素材可以分别配置：
- Endpoint
- 模型ID
- API Key
- 单次生成价格
- 供应商

重要原则：
**预算确认之前不调用素材生成服务。**

## 12. 商品资料
支持淘宝/天猫、京东、拼多多、1688、抖音等平台的资料采集；HTTP读取失败时可使用本地浏览器回退。

## 13. 合规与字体
支持本地禁止词库。字幕字体原则：只使用允许商业使用的免费字体，不使用未经授权的付费/商业字体。

## 14. 系统状态
检测：
- CPU / RAM / GPU能力
- CUDA / ROCm / Metal等后端
- FFmpeg
- 可用硬件编码器
- AI模型池
- 模型调用凭据
- 独立模型路由
- 浏览器回退采集
- 禁止词库
- 本地资产库
- 视频Provider
- 本地后处理
- 最终拼接

## 15. 成本账本
本机记录：
- 时间
- 功能
- 模型
- Provider
- 状态
- Token
- 估算成本
- 调用耗时
- 错误信息

生产阶段还会把**实际资产生成费用**和**实际视频镜头费用**写入同一本本地账本，并按项目ID汇总到项目工程的 `actual_cost_rmb` / `actual_cost_summary`。模型调用、素材生成、视频生成分别记录；本地生成费用为 ¥0；云端按当前Provider配置的单次实际价格记录。重新生成同一镜头会保留历史费用记录，不会覆盖旧账。

## 16. 当前已知限制
以下仍需真实供应商适配才能称为完全可用：
- 不同人物/场景生成平台的具体API协议。
- 不同视频生成平台的具体API协议。
- 高质量AI配音Provider。
- 更完整的“已有素材本地加工”自动判断与加工链。
- 实拍视频目前以关键帧视觉分析为主；逐字语音转写、口播废话自动删除、逐帧动作级评分尚未完全接通。

不得把代码框架存在冒充为真实服务已经接通。

## 16. AI接手与文档同步
本项目根目录的 AGENTS.md 是强制开发协议。

任何 AI 修改桌面端代码，都必须：
1. 先阅读 AGENTS.md、PROJECT_LOGIC.md、HELP.md。
2. 修改代码。
3. 同一次修改更新 PROJECT_LOGIC.md。
4. 同一次修改更新 HELP.md。
5. 更新两个文档的更新记录。
6. 运行文档同步检查和可用测试。

GitHub Actions 会检查桌面代码变更是否同时修改两个核心文档。检查失败代表任务没有完成。

## 2026-10-08：实拍视频视觉分析链
新增用户实拍素材的本地关键帧抽取与视觉模型分析。模型可结合商品资料和创意方案判断素材可用性、卖点对应、商品遮挡、人物/场景、重复、糊片/抖动等，再把分析结果交给素材剪辑导演规划起止时间；关键帧只在启用视觉输入的模型上发送。

# 更新记录

## 2026-10-07
### 多商品类型创意方案测试能力
新增“创意方案数 1/3”。同一商品可由 AI 自动生成多个明显不同的广告打法，适用于酒、食品、美妆、家电、服装、数码等不同商品，不把任何一个测试案例写死为系统模板。


## 2026-10-07
### 资产库独立硬盘
新增资产库位置设置。演员、场景、商品素材等长期资产可以保存到用户指定硬盘；项目工程与资产库分离；云端生成的新资产写入独立资产库。

### 项目成本预估
创建项目正式展示视频、演员、场景、商品素材四类生成费用及总费用，并与本次预算比较。

### 资产成本去重
同一演员/场景/商品素材需求跨多个镜头时，预估只计算一次。

### 预算确认
预算确认前不进入正式云端素材生成调用链；取消则退出项目创建。

### 资产生成设置
增加演员、场景、商品素材独立Provider设置。

### 本地资产优先
生产阶段优先寻找本地可复用资产；缺失时才进入自动生成逻辑，并将生成结果登记到资产库。

## 2026-10-08：硬件能力进入生产后处理
ProductionStore.postprocess_shot 会读取当前硬件能力画像，并在状态中记录本地执行策略；实际编码由 FFmpeg 的动态编码器选择器决定，不再固定使用 RTX 4050/NVENC。


## 2026-10-08：本地素材生成执行链修正
本地素材生成现在兼容填写 `http://127.0.0.1:7860` 或完整的 `/sdapi/v1/txt2img` endpoint，不会重复拼接路径；系统状态同时按“演员”类型检测素材生成能力。创意模型独立路由数量显示与实际功能列表保持一致。


## 2026-10-08：CI 修复
修复 FFmpeg concat 清单写入的 Python 语法错误，避免桌面 CI 在 `compileall` 阶段失败。


## 2026-10-08：视频生成失败安全机制
重新生成单个镜头时先写临时文件；只有视频生成成功并确认文件有效后才替换正式版本。若 v2 生成失败，v1 不会被删除，镜头会明确显示“生成失败（已保留上一版本）”。


## 2026-10-08：镜头参考素材传递
生成镜头时，系统会把已解析的演员、场景、商品素材同时作为 asset ID 和真实本地文件引用传给 Provider。支持参考图的 Provider 可在配置中启用 `embed_reference_assets`，由通用适配器把图片内嵌发送；不同供应商若有自己的参考图字段或上传协议，仍需要对应专用适配器。


## 2026-10-08：实际成本字段统一
项目文件现在保存实际成本总额和分类汇总；生产执行统一入口写账，避免资产费用与视频费用重复记录。
