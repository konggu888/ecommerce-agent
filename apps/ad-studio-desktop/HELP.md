# AI 商品广告工厂（桌面版）帮助文档

> 本文是项目的长期功能说明书。以后每增加、修改或修复一项用户可见功能，都必须同步更新本文件的“功能总表”和“更新记录”。

## 1. 产品定位
AI 商品广告工厂是 Windows 本地桌面软件：
- 本地计算设备负责能高效完成的编排、素材管理、视频加工、FFmpeg 后处理和最终合成；系统自动检测硬件能力。
- 云端只负责本地难以生成的高质量素材/视频任务。
- 本地资产库优先复用；没有合适素材时才允许自动生成。
- 生成后的可复用素材进入本地永久资产库。
- 项目工程、成片和资产库分开储存。
- 云端成本在真正调用前预估并展示。

## 2. 完整工作流
商品链接 → 商品资料采集 → AI商品理解 → 卖点提炼 → 人群与痛点 → 广告策略 → 广告强度 → 视频形式 → 剧本 → 分镜 → 每镜头资产需求 → 项目级成本预估 → 用户预算确认 → 本地资产匹配 → 缺失资产按需云端生成 → 资产永久入库 → 云端镜头生成 → 本地硬件/FFmpeg后处理 → 字幕/音频/BGM → 最终拼接。

## 3. 创建广告项目与预算
用户可以为每个项目输入自己的预算，例如 ¥3、¥5、¥10、¥50。

创建前显示：
- 视频生成费用
- 演员生成费用
- 场景生成费用
- 商品素材生成费用
- 本地处理费用
- 总费用

如果总费用超过本次预算：
- 明确显示超预算。
- 明确询问是否继续。
- 不自动换模型。
- 不自动降低质量。
- 不自动减少镜头。
- 不自动改变广告方案。

用户取消：
- 不保存新项目。
- 不开始后续云端素材生成。
- 不产生后续云端素材调用费用。

## 4. 成本计算
- 视频成本按计划镜头数 × 当前视频Provider价格。
- 演员/场景/商品素材成本按本地缺失的唯一资产需求计算。
- 同一资产需求跨多个镜头只计一次。
- 价格来自本机Provider配置；占位价格不能冒充供应商正式报价。
- 实际生成后记录实际发生费用。

## 5. 本地资产库
资产类型包括演员、场景、商品素材、BGM。

匹配原则：
**本地优先 → 可复用直接复用 → 可加工则本地加工 → 没有合适素材才自动生成。**

AI生成的新资产：
- 自动保存到本地资产库。
- 获得稳定资产ID。
- 后续项目优先复用。
- 避免相同演员/场景反复付费生成。

## 6. 资产库可自定义硬盘
为了避免系统盘爆满，资产库支持独立硬盘目录。

例如：
- D:\AI广告素材库
- E:\电商资产库
- F:\广告工厂\Assets

桌面端入口：
**💾 资产库位置 → 选择硬盘目录 → 保存并切换**

资产库与项目工程目录分离。切换位置不会自动删除旧资产，也不会偷偷搬迁旧资产。

## 7. 多模型AI创意引擎
当前独立路由：
- 商品理解
- 卖点提炼
- 人群与痛点
- 广告策略
- 广告强度判断
- 视频形式判断
- 剧本
- 分镜
- 素材选择

默认GPT；不同功能可以使用不同模型，也支持本地模型。

### 多创意方案
同一个商品可以一次生成 1 或 3 个彼此明显不同的广告方案。
- 每个方案仍经过独立的商品理解、卖点、人群、策略、强度、视频形式、剧本、分镜、素材选择流程。
- 系统会把前一个方案的打法传给后续方案作为“避免重复”的约束，而不是固定把某个行业硬套成某一种视频。
- 用户可以在同一个项目中切换方案，再分别生成镜头和成片。
- 方案数量为 3 时，系统目标是测试三个不同的广告机制，而不是只改标题或换几句文案。
- 云端视频/素材成本按当前选中的方案单独预估；切换方案后需要重新确认当前方案成本。

## 7.1 多版本创意分析（投放前）
“🧠 创意方案分析”只分析已经生成的创意方案本身，不假设用户要投放到哪个平台，也不凭空产生 CTR、CVR、CPA、ROAS 等数据。

分析内容包括：
- 每个方案到底在测试什么创意轴。
- Hook/开场、核心策略、核心卖点、证明方式、行动引导和目标人群的差异。
- 两两方案的结构差异，避免只改字幕、颜色等表面元素却宣称是不同打法。
- 下一轮应该继续强化或拉开哪些创意差异。

真实投放数据是独立的可选层。只有用户实际投放后主动提供对应平台的真实数据，系统才记录并计算投放指标；系统不会自行决定抖音、淘宝、拼多多、小红书或京东，也不会把模拟数据当成真实数据。
在投放前，系统还会做一次确定性的“创意实验设计审计”：区分核心机制变化与表层文案变化，并检查两两方案是否只改变一个核心机制。它只评价“这个实验设计是否干净”，不评价哪个平台、哪个方案实际赚钱。

## 7.2 AI短剧编导（新增独立创作模式）

在创建或打开商品项目后，点击顶部“🎭 AI短剧编导”。系统使用独立的“AI短剧编导”模型路由，根据商品资料自主选择题材，设计人物关系、剧情冲突/反转、完整剧本、可执行分镜和镜头资产需求，并提供不同故事方向备选。

- 短剧方案单独保存在项目 `creative_plan.short_drama` 中。
- 不覆盖原有电商短视频/商品主图/广告投放创意方案。
- 启动前会提示模型调用；模型费用按所选路由模型配置记录。
- 本阶段只生成策划与分镜，不会自动触发云端素材/视频生成，也不会声称已经产出短剧成片。
- 完整短剧分镜接入现有演员/场景/商品资产匹配、成本预估、镜头生成、单镜头替换和最终合成仍是后续开发与验收项。

## 7.3 短剧分镜进入独立生产链（新增）

在短剧创作方案窗口点击“建立独立短剧制作项目”，系统会先展示镜头数、视频生成费用、缺失演员/场景/商品素材费用、本地处理费用和总费用，并询问是否继续。确认前不调用素材/视频生成服务。

- 短剧制作会创建一个新的独立项目，不覆盖原广告项目、原分镜或创意方案。
- 短剧分镜会映射到现有镜头生产模型，并传递人物、场景、商品素材需求给本地资产匹配流程。
- 镜头时长传递给视频 Provider；单镜头生成、重新生成、后处理与最终合成复用原生产链。
- 创建项目不等于开始生成；用户仍需逐镜头触发生成，费用按当前 Provider 配置估算。
- 短剧专属的事实/风险复核与完整端到端验收仍在后续开发中。

## 8. 本地硬件能力 / FFmpeg
## 8.1 本地实拍视频 AI 自动剪辑

桌面端现在有独立的“用户拍摄素材”工作流：
**商品资料 + 用户实拍视频文件夹 → 关键帧视觉分析 → 卖点/商品/人物/场景/重复/遮挡/糊片等判断 → AI剪辑导演 → 本地FFmpeg裁剪 → 后处理 → 成片**。

实拍分析不再只看文件名、时长和分辨率。系统会从每个可解析视频均匀抽取少量低分辨率关键帧；启用“支持图片/视频帧分析”的模型后，关键帧会作为视觉输入交给“素材剪辑导演”。视觉分析结果保存到项目的 `creative_plan.footage_visual_analysis`，后续剪辑导演再根据这些结果决定具体起止时间。

模型设置新增：
- **支持图片/视频帧分析**：实拍视觉分析必须打开。
- 默认 GPT 模型会预设开启；自定义本地/云端模型必须确认自身接口支持图片输入。

注意：当前分析粒度是“关键帧视觉分析”，不是把整段视频作为原生视频文件直接交给模型。口播逐字稿、逐帧动作识别、自动人声去废话仍需后续接入专门的视频理解/转写能力。

已接入：
- GPU检测
- FFmpeg检测
- NVENC硬件编码
- 画幅适配
- 裁切
- 缩放
- AI构图坐标执行
- 速度调整
- 转场
- 字幕烧录
- 人声/BGM混音
- 最终视频拼接
- 镜头版本化

支持9:16、1:1、16:9。

### 实拍重复镜头识别与最佳版本选择
视觉分析现在还会把同一拍摄动作/卖点的重复镜头进行分组，并比较清晰度、构图、商品展示完整度、动作完成度、口播质量和广告价值，输出最佳版本（`best_take`）及优先级（`take_rank`）。剪辑导演会优先使用最佳版本，避免同一镜头的低质量重复素材进入成片。重复素材不会因为“重复”就自动删除；只有明确判定不可用的素材才进入废片库。

### 实拍废片自动归档
视觉分析完成后，系统会自动处理两类明确不可用素材：
- AI 明确返回 `usable=false` 的素材，例如明显糊片、严重遮挡、严重抖动或没有广告价值的素材。
- FFmpeg 无法解析的素材。

这些文件会从原实拍文件夹**移动**到同级的 `05_废片库/<项目ID>/`，不会直接删除；系统同时写入 `archive-manifest.json`，记录原路径、归档路径、原因和视觉标签。只有成功移动的文件才会从后续剪辑候选中剔除。若移动失败，原文件继续保留并进入后续流程。

桌面端顶部提供 **📹 实拍分析报告**。创建或打开实拍项目后，可直接查看每个素材的 AI 评分、是否可用、废片原因、画面标签、推荐片段和口播质量，以及总体建议时长和废片归档数量。

## 商业剪辑决策：按镜头目的推断默认参数（A106）
当 AI 分镜没有明确给出镜头时长、节奏或转场时，创意引擎会根据分镜文本中的商业角色关键词，给出可追溯的保守默认值：
- 开场钩子：2 秒、较快节奏、硬切。
- 商品细节/特写：4 秒、较慢节奏、交叉溶解。
- 功能/使用演示：5 秒、标准速度、硬切。
- 证据/对比：4 秒、较慢节奏、交叉溶解。
- 痛点、人物反应及 CTA 使用各自默认值；末镜头 CTA 默认淡出。
- AI 显式给出的时长、速度、转场优先，系统不覆盖用户/模型的明确决定；决策结果保存镜头角色、理由、依据及参数来源，便于追溯。
- 这是对分镜文本的规则回退，不是对真实画面的视觉理解。未知 pacing 标签固定回退“标准”；决策记录同时保存最终生效的时长、节奏、速度、转场及参数来源。商业剪辑决策层仍未整体完成，真实画面、音乐卡点、字幕密度和剪后反馈继续待开发/验收。

## 成片视觉复核

“🎥 成片视觉复核”会把实拍关键帧视觉分析结果映射到各方案实际使用的素材，重点提示商品遮挡、模糊、抖动、不可用素材等风险。它不是虚构的效果数据，也不会把“需复核”自动改成通过。


## 最终成片交付质检与清单

最终安全闸门通过后，系统会先将最终拼接结果归一化转码到最低 1080P 级输出配置：竖屏 1080×1920、横屏 1920×1080、方形 1080×1080；随后对实际输出文件执行机器质检，检查文件存在且非空、存在视频流、可读取时长和尺寸、画幅与最低分辨率是否符合本次要求。质检失败会删除不合格输出并阻止交付。低分辨率源素材会被放大到目标尺寸，但放大本身不等于恢复源素材中不存在的细节。通过后会在最终视频旁写入同名 JSON 交付清单，记录方案编号、画幅、实际镜头组成、安全闸门结果和媒体质检结果。

## A70：短剧故事结构检查

## A71：备选故事方向差异化

## A73：剧情事件因果链
