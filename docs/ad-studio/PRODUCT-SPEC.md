# Ad Studio — AI商品广告工厂

## 目标
淘宝、京东、拼多多、1688、抖音商品链接 → 商品理解 → 广告策略 → 演员 → 剧本 → 分镜 → 视频 → 自动剪辑 → 成品。

## 广告强度
1. 纯种草
2. 轻广告
3. 标准广告
4. 强转化
5. 极强转化

## 自动判断
根据商品类型、目标人群、卖点、痛点、场景自动选择广告强度、视频形式、人物组合、场景、开头钩子和 CTA。支持真人口播、真人剧情、产品展示、真人+产品、生活场景、街头采访、情侣、夫妻、家庭、职场、开箱、测评、对比、教程、POV、UGC、直播间风格、电影感、短剧等。

## 人物库
人物带结构化标签：性别、年龄段、职业、气质、穿衣风格、性格、适用场景、目标人群适配度。支持男主、女主、配角选择，以及 AI 自动选角。

## 生成阶段
A. 商品分析：商品名、类型、核心卖点、证据、目标人群、痛点、使用场景、价格/优惠（若可读取）、风险提示。
B. 广告策略：至少 3 个候选策略 + 推荐方案。
C. 剧本：镜头时长、台词、动作、场景、景别、镜头运动、产品出现、字幕、BGM 情绪、音效、CTA。
D. 分镜：先出分镜图/视觉草图。
E. 用户确认：确认后才进入视频生成。
F. 视频：按镜头生成，再自动拼接、配音、字幕、音乐、音效。

## 成本控制
目标：单条成片 ≤ ¥3。生成前显示文本、图片、视频、配音及其他成本和总预计成本。

### 超预算硬规则
预计成本 > ¥3 时：
1. 停止进入付费生成阶段；
2. 明确显示预计成本和超出金额；
3. 等待用户确认；
4. 不得自动切换模型、降画质、减少镜头或改变方案；
5. 用户确认后才继续。

## 批量广告
一个商品可生成多套不同钩子、人物、场景、广告强度和表达方式，用于素材测试。

## 局部修改
支持只重做商品理解、策略、人物、场景、文案、单个镜头、配音或字幕。修改单镜头不得默认重新生成整条视频。

## 第一版 UI
商品链接 → 自动识别 → 商品分析 → 广告强度 → AI/手动视频形式 → 男演员 → 女演员 → 配角 → 广告方案 → 分镜 → 成本预估 → 确认生成 → 进度 → 成片 → 单镜头重生成 → 导出。

## 原则
用户只提供商品，系统完成广告生产；成本透明；人工确认；局部重生成；平台适配器可替换；无法可靠读取商品信息时明确提示，不伪造数据。
