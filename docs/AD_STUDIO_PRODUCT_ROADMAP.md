## 1. 产品终点：我们要建成什么

打造一款面向电商商家的本地桌面 AI 商业视频生产系统：用户提供商品资料/实拍素材、广告目标与预算后，系统逐步具备自主分析商品、规划广告创意、组织人物/场景/商品资产、生成分镜、制作与剪辑视频、检查事实/画面/声音/字幕、管理成本并交付成片的能力。

系统不以“功能数量多”作为成功标准，而以能否稳定地把商业意图转化为可信、可修改、成本可控的成片为目标。

### 四项核心能力
1. **商业判断**：理解商品、人群、痛点、卖点、广告目的和表达限制。
2. **创意编导**：选择合适的广告形式，形成剧情/脚本/分镜与资产需求。
3. **商业制作**：将创意真正落实为画面、镜头时长、节奏、转场、声音、字幕和成片。
4. **质量与成本控制**：核验商品真实性、交付质量、失败恢复、素材复用、局部修改和预计/实际成本。

## 2. 统一原则（所有 AI 必须遵守）

- **代码事实优先**：先读当前代码和测试；文档、PR 描述、聊天历史、旧验收记录都不能替代当前证据。
- **阶段门槛优先于功能堆叠**：每个任务必须说明它服务哪个阶段目标、如何验证、是否阻塞后续工作。
- **真实执行优先于字段存在**：计划/报告中有参数不等于参数进入实际生产链；必须追踪到实际执行位置并测试。
- **测试层级不能混淆**：单元测试、模块集成、模拟端到端、真实环境/素材验收分别报告，不互相冒充。
- **失败先修复**：最新相关 CI 失败或运行中时，不叠加无关功能；先读日志、定位、修复并重新验证。
- **不无限开发**：每个阶段都有可验证的退出条件；满足退出条件后复盘，再决定下一阶段，不因“还有想法”而无止境扩张。
- **真实商品优先**：商品外观、结构、关键功能、规格和使用方式不能为剧情效果而随意改变。
- **预算透明**：生成前预估成本并让用户确认；超过预算提醒并询问是否继续，不擅自阻断或偷偷降低质量。
- **最低输出尺寸**：最终成片至少 1080P 级（9:16 1080×1920、16:9 1920×1080、1:1 1080×1080）；像素放大不等于恢复真实细节。
- **用户边界不可越过**：PR #32 不合并；Windows 真机、真实素材、真实 Provider/实际扣款、剪映现场验收继续暂缓，除非用户另行明确安排。
- **每轮可接手**：独立工作单元结束时，更新接手文件中的真实 HEAD、CI/doc-sync 状态、完成证据、未完成项和下一步。

## 3. 阶段路线与退出条件

### 阶段 0｜路线与证据基线（本阶段已建立路线图，后续按实际状态持续盘点）
**目的：** 把功能实现、自动化证据、真实能力和未验证风险分开，避免重复开发与误判。

退出条件：
- 每项关键能力都能区分“代码存在”“测试通过”“真实能力已验证”。
- 明确当前瓶颈、依赖和下一项任务。
- AI 接手文件与当前分支/HEAD/CI/下一步一致。

### 阶段 1｜可靠的生产底座（持续维护，不重复造轮子）
**目标链路：** 商品输入 → 商品分析 → 广告策略 → 人物/场景/商品资产 → 分镜 → 单镜头生产 → 后处理 → 质量/安全闸门 → 成片与交付清单。

重点：
- 数据在模块间正确传递，项目/方案/镜头/版本隔离。
- 局部重做不无故重做其他镜头，资产与历史可复用。
- 失败状态明确，旧版有效输出可恢复，成本账本不因异常重复计费。
- 文档、测试、代码的真实行为一致。

退出条件：核心链路的关键输入、决策、执行、持久化、失败处理和交付均有专项自动化证据；已知限制明确。真实环境验收仍按用户安排暂缓，不能因此伪称全产品真实验收完成。

### 阶段 2｜商业级剪辑决策层（当前主攻阶段）
**目标：** 从“能拼接视频”升级为“能根据内容和商业目的做出可解释、可执行的剪辑决策”。

能力范围：
1. 镜头商业角色、排序、节奏、时长与广告结构。
2. 音乐节拍与实际画面切点联动，音乐时间轴连续。
3. 商品展示时长、主体可见性与信息理解优先。
4. 画面转场、原音轨、人声、字幕和背景音乐协调。
5. 字幕时间轴/信息密度与实际镜头时长协同。
6. 根据可靠证据决定调整；不可靠时保守回退。
7. 最终画幅/帧率/分辨率/媒体流质检，输出至少 1080P 级。
8. 后续再逐步加入更高级的内容/情绪/转化节奏、自动时长和剪后质量反馈。

#### A109｜音乐节拍与画面切点联动（自动化实现已接通，真实质量待验）
项目级连续 BGM、节拍候选/置信度、实际镜头时长规划、同步变速、拼接后统一混音和 1080P 归一化已进入最终生产链。低置信度、超限调整、短镜头及交叉溶解场景均保守回退。该能力仍不代表真实节拍识别、音画听感或商业成片质量通过验收。

#### A110｜内容保护约束音乐卡点（已实现，自动化 CI 通过）
最终拼接读取实际镜头时长，并结合分镜台词/脚本、屏幕文字、商品资产需求、商品细节/演示/证据角色与 CTA 估算最低停留时长。若原镜头或拟议切点低于保护下限，规划器保守保留原切点；逐镜头保护依据写入项目音乐同步审计。此能力基于文本/结构化字段，不代表真实画面理解、语音识别或商业质量验收。

#### 当前下一项：A111｜逐边界的局部卡点规划
- 在 A110 内容保护下，不再因为某一个镜头存在保护冲突就必然冻结所有边界。
- 每个候选切点须同时检查相邻镜头的保护下限、最短时长、最大变化量、变速范围和前后边界约束。
- 只接受安全的边界；冲突边界保留原位置，不能让局部调整导致其他镜头时长越界或总时间轴漂移。
- 测试覆盖一个受保护镜头、多个相邻保护镜头、边界相互影响、低置信度、交叉溶解与无效输入。
- 这是结构化内容保护与节拍规则，不代表真实视觉理解；真实素材/Windows 验收继续暂缓。

阶段退出条件：
- 关键剪辑决策有明确理由、证据边界、最终生效参数和参数来源。
- 关键决策进入真实生产链且有执行层测试。
- 核心剪辑回归、完整 CI、docs-sync Push/PR 均通过。
- 已知未验证事项写清楚，不能把规则回退说成视觉语义理解。

### 阶段 3｜AI 广告编导
**目标：** 系统不只执行用户给出的方案，还能从商品、人群、卖点、广告目标和预算出发，决定适合的广告形式与创意结构。

顺序：商品事实与人群理解 → 策略候选 → 选择理由/约束 → 剧本/分镜 → 资产需求 → 实际生产 → 对照策划检查成片是否兑现。

退出条件：策略不只是文字；策略决定能追踪到分镜和生产参数；生成结果可检查；商品事实与合规边界受保护。

### 阶段 4｜AI 短剧能力
分两条路线，共享资产库、分镜、生产和剪辑基础设施，但目标不同：
- **商品短剧广告**：AI 判断题材，商品自然进入剧情，同时严格保持商品真实外观、结构、功能和使用方式。
- **非商品 AI 短剧**：可完全不带商品，重点是剧情因果、人物知识、人物关系、跨集状态、悬念与连续性。

优先顺序：先补强与电商主线关联更紧密的商品短剧编导和商品融入；再持续发展通用/多集短剧。不能把结构化台账检查说成真正的剧情语义理解或真实画面一致性。

退出条件：创意到分镜到生产链真正接通；关键剧情与人物/商品一致性检查有专项测试；未实现的视觉/语义能力明确标记。

### 阶段 5｜资产与制作效率深化
- 素材质量评分、废片原因、版本选择、重复素材归并和素材使用历史。
- 授权明确的免费商用音乐库、音乐标签与实际成片节奏匹配。
- 免费商用字体白名单。
- 商品知识库、多 SKU/规格、资料版本和重新索引。
- 商品遮挡判断、替代镜头、重构图和再次核验。
- AI 能力调度器与三种 AI 工作模式，按现有架构依赖和实际收益择序推进。

每项均需说明对成片质量、生产可靠性、成本或用户操作的明确收益，不因技术新颖而自动排高优先级。

### 阶段 6｜真实环境与商业验证（按用户许可启动）
**当前暂缓。** 包括 Windows 真机、真实素材、真实 Provider、真实扣费/账单核对、剪映现场和真实投放反馈。
用户明确允许启动前，继续做离线代码、确定性夹具和自动化测试，但不得宣称真实环境或商业效果已验收。

未来按层次验证：
1. Windows 桌面应用与本地媒体链路。
2. 真实素材的画面、声音、字幕和商品真实性。
3. 真实 Provider 能力、费用预估与实际费用差异。
4. 用户实际使用效率与成片可用性。
5. 只有用户提供真实投放数据后，才开展真实 CTR/CVR/ROAS 等反馈分析；不得编造数据。
