# 桌面项目阶段性验收计划

建立日期：2026-10-09

> **本文件不是“广告投放模块验收表”。**
> 本文件用于验收整个桌面项目的完整能力、基础架构、用户流程、安全边界、数据、AI能力、视频生产、工程稳定性以及最终交付。
>
> 广告投放只是整个桌面项目中的一个任务类型/后续能力，不代表项目验收范围。

## 1. 验收总目标

最终要回答的不是“某个功能有没有写出来”，而是：

**用户拿到这个桌面项目后，能不能从创建任务开始，一路完成真实的本地工作，并在出现问题时知道为什么、在哪里修复、修复后能否继续，最终得到可信的结果。**

验收必须覆盖：

- 桌面应用本身
- 项目/任务管理
- 用户输入与配置
- 三类任务
- 素材管理
- 商品资料
- AI分析与决策
- 视频剪辑/生产
- 混合实拍+AI流程
- 字幕/音频/字体/广告合规
- 多版本
- 风险控制
- 数据持久化
- 工程文件
- 成片输出
- 历史与交付
- 异常恢复
- 帮助文档
- CI与自动化测试
- 平台能力边界
- 真实投放能力（单独验收，不能伪造）

## 2. 三类任务必须分别验收

桌面项目启动时的任务选择：

- [ ] **电商短视频**
- [ ] **商品主图视频**
- [ ] **广告投放视频**

要求：

1. 一次任务只能选择一个任务类型。
2. 三类任务不能因为共用代码而错误地使用同一套成片逻辑。
3. 每一种任务都必须有自己的验收用例。
4. 广告投放视频的“投放前创意分析”不能代表另外两类任务已经验收。
