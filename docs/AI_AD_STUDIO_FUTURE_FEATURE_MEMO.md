**用户把原始素材放入工作区 → Codex/AI 接收任务 → AI 分析与决策 → 调用剪映专业版 → 自动完成剪辑 → 导出成品。**

## 2. 三种 AI 工作模式完整落地

### 目标

把项目真正做成三种使用方式：

1. **AI 全自动**：用户提供素材和任务，AI 自主分析、决策、执行、检查、交付。
2. **AI 半自动**：AI 提出方案，用户在关键节点确认/修改，AI继续执行。
3. **用户控制 / AI 辅助**：用户控制关键决策，AI负责分析、建议和执行辅助。

### 尚未完成

- 三种模式的完整 UI / 状态机。
- 模式之间的权限与人工确认边界。
- 关键节点暂停、确认、修改、继续。
- 同一项目在不同模式下安全切换。
- 三种模式的完整端到端真机验证。

## 3. AI 能力调度器

### 目标

不是把某个任务永久写死给某个模型，而是让 AI 根据任务自主判断应该调用哪种能力：

**任务分析 → 能力判断 → 选择 Provider / 模型 / 工具 → 执行 → 检查 → 必要时换能力重试。**

### 尚未完成

- 本地视觉模型、云端模型、TTS、视频生成、OCR、视频处理、剪映等能力的统一调度。
- 根据任务难度、成本、质量、可用性选择 Provider。
- Provider 失败后的替代路径。
- 能力调用记录与可解释原因。
- 模型/Provider 可插拔而不破坏核心业务逻辑。

### 原则

**LLM 负责思考和决策，具体工具负责执行。**

## 4. AI 编导生成短剧

### 目标

在已有短剧编导、分集规划和独立成片基础上，继续补齐完整的 **AI 编导 / AI 短剧创作能力**。

AI 不只是生成几个镜头，而是承担“编导”的角色：

**商品理解 → 短剧方向判断 → 剧情设计 → 人物设计 → 场景设计 → 冲突/反转 → 台词 → 分镜 → 镜头资产需求 → 生成/匹配素材 → 剪辑成片**

### 已落地的基础能力

- 已支持单集、连续多集、系列短剧的分集规划与独立成片。
- 已增加通用 AI 短剧、商品植入短剧、商品转化短剧三个创作目标；通用模式允许完全不带商品。
- 创作目标与分集结构分开配置，并校验模型返回的创作目标，避免用户选通用短剧却生成强制带货内容。

### 尚未实现的未来能力

- 根据商品自动判断适合的短剧类型。
- 根据目标人群、卖点、使用场景确定剧情方向。
- 自动设计人物、关系、场景、冲突、节奏和结尾。
- 自动生成完整短剧脚本。
- 自动拆分为可执行分镜。
- 自动判断每个镜头需要真人、AI生成画面、商品素材还是实拍素材。
- 支持多种剧情方案和商业转化方案。
- 最终输出完整的商品短剧。

### 原则

AI 编导不能简单套用固定行业模板，应根据商品本身重新判断最合适的故事机制。

## 5. 商业级剪辑决策层升级

A0–A33 已经完成基础剪辑生产链、多版本、检查和交付闭环，因此本节只保留**尚未实现的更高阶商业剪辑能力**。

### 尚未实现的未来重点

- 更高级的镜头衔接质量判断。
- 基于画面内容的动态节奏控制。
- 情绪递进与商业转化节奏联合优化。
- 音乐节奏与画面节奏的自动精细匹配。
- 更高级的卡点与转场决策。
- 字幕节奏与信息密度的联合优化。
- 商品展示节奏的精细控制。
- 根据广告目标动态调整开头、中段、结尾的结构强度。
- **AI 自动决定最终成片时长**，而不是只使用固定时长范围。
- 建立真正面向商业使用的 **AI 剪辑决策层**，而不是主要依赖基础镜头排序、裁切和拼接。

### 核心要求

未来升级重点不是增加更多“剪辑动作”，而是让 AI 能够解释并自主决定：

**为什么这样剪 → 为什么这样排序 → 为什么这里快/慢 → 为什么这个卖点放这里 → 为什么这个版本应该这样变化。**

## 6. 商品主体遮挡与智能重构图

### 目标

当商品被人物或其他物体遮挡，AI 应判断商品主体可见性，并决定是否：

**换镜头 → 调整镜头顺序 → 裁切 → 缩放 → 特写 → 调整字幕位置 → 重新构图 → 再检查。**

### 尚未完成

- 商品主体遮挡程度判断。
- 判断当前镜头是否仍然可用。
- 自动寻找替代镜头。
- 自动裁切/缩放/重构图。
- 保证商品主体和关键事实不因重构而丢失。
- 重构后的再次视觉事实检查。

## 11. AI 短剧形式商品广告

### 目标

增加一种独立的商品广告生产模式：

**商品分析 → 判断适合的短剧世界/题材 → 设计剧情 → 商品进入剧情 → 用短剧形式自然介绍商品 → 完成转化**

### AI 自动判断方向

例如现代都市、古代、职场、家庭、悬疑、搞笑、反转、情感、科幻、奇幻、生活场景等。

**不是固定从列表机械选择。**

AI 应根据商品、人群、卖点、使用场景和广告目标，自主判断更合适的短剧形式。

### 重要真实性原则

商品外观、结构、核心功能、关键使用方式和商品事实，不能因为 AI 生成剧情而被随意改变。

## 12. 真实投放数据适配层

> **暂不开发。**

只有用户实际投放后主动提供真实平台数据，系统才进入这一层。

### 未来能力

- 接收真实平台投放数据。
- 明确具体平台后建立对应数据适配器。
- 比较不同创意版本的真实结果。
- 根据真实结果进行创意归因。
- 将真实结果反馈给下一轮创意设计。
- 建立“创意 → 投放 → 数据 → 学习 → 下一轮创意”的闭环。

### 数据边界

- 不默认抖音、淘宝、拼多多、小红书或京东。
- 不伪造 CTR / CVR / CPC / CPA / ROAS。
- 不把模拟数据当真实投放结果。
- 平台适配器与平台无关的创意分析层分离。
- 只有真实数据进入后，才允许进行真实结果比较和反馈优化。
