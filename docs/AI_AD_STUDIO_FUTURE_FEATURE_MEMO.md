## 1. AI 编导生成短剧

### 目标

增加完整的 **AI 编导 / AI 短剧创作能力**。

AI 不只是生成几个镜头，而是承担“编导”的角色：

**商品理解 → 短剧方向判断 → 剧情设计 → 人物设计 → 场景设计 → 冲突/反转 → 台词 → 分镜 → 镜头资产需求 → 生成/匹配素材 → 剪辑成片**

### 未来能力

- 根据商品自动判断适合的短剧类型。
- 根据目标人群、卖点、使用场景确定剧情方向。
- 自动设计人物、关系、场景、冲突、节奏和结尾。
- 自动生成短剧脚本。
- 自动拆分为镜头。
- 自动判断每个镜头需要真人、AI生成画面、商品素材还是实拍素材。
- 支持 AI 生成素材与用户真实素材混合。
- 支持多种剧情方案和商业转化方案。
- 最终输出可用于商业传播的完整商品短剧。

### 原则

AI 编导不能简单套用固定行业模板，应根据商品本身重新判断最合适的故事机制。

## 2. 商业级剪辑能力完善

### 目标

当前剪辑链路继续建设，但后续需要进行一次专门的 **商业级剪辑能力升级**。

目标不是“把镜头拼成视频”，而是让 AI 剪辑真正达到商业使用和广告投放所需要的水平。

### 覆盖范围

同时覆盖：

- AI 自动生成的视频剪辑
- 用户实拍素材剪辑
- AI + 实拍混合素材剪辑
- 商品广告剪辑
- 电商短视频剪辑
- 商品主图视频剪辑
- 广告投放视频剪辑

### 未来重点

- 更专业的镜头衔接
- 镜头长短动态调整
- 节奏控制
- 情绪递进
- 音乐与画面节奏匹配
- 卡点
- 转场控制
- 字幕节奏
- 商品展示节奏
- 信息密度控制
- 开头 1–3 秒强化
- 中段卖点递进
- 结尾 CTA 强化
- 不同平台适配
- 不同广告目标适配

- A/B 测试剪辑策略

### 核心要求

以后需要建立一套真正面向商业使用的 **AI 剪辑决策层**，而不是只依赖简单的镜头排序、裁切和拼接。

## 3. AI 短剧形式商品广告

### 目标

增加一种独立的商品广告生产模式：

> **商品分析 → 判断适合的短剧世界/题材 → 设计剧情 → 商品进入剧情 → 用短剧形式自然介绍商品 → 完成转化**

### AI 自动判断的方向

例如：

- 现代都市
- 古代
- 民国
- 职场
- 家庭
- 情侣
- 悬疑
- 搞笑
- 反转
- 情感
- 科幻
- 奇幻
- 生活场景
- 其他由商品分析后决定的形式

**不是固定从上述列表中机械选择。**

AI 应根据商品、人群、卖点、使用场景和广告目标，自主判断更合适的短剧形式。

### 商品融入方式

商品不是简单地贴在视频上，而是作为剧情中的真实商品信息进入故事：

**商品图片 / 外观 / 功能 / 使用方式 / 核心卖点**
→
**融入人物行为和剧情**
→
**自然完成商品展示**
→
**剧情推动商品认知**
→
**结尾完成转化**

### 重要真实性原则

商品的真实外观、核心功能、关键卖点不能因为 AI 生成剧情而被随意改变。

尤其是：

- 商品外观
- 商品结构
- 核心功能
- 关键使用方式
- 商品事实

需要优先保持真实。

## 4. 2026-10-08 项目当前进度与下一阶段待推进事项

### 当前已完成到的位置

当前主线已经推进到：

**实拍素材分析 / 缺口判断**
→ **补拍 / AI补镜头决策**
→ **实拍 + AI 混合制作**
→ **广告创意多版本生成**
→ **投放前创意版本分析**
→ **创意实验设计审计**

已经明确建立两条不同的数据边界：

1. **投放前层**：只分析商品、素材、卖点、创意机制和版本差异，不猜测投放平台，不生成虚假的 CTR / CVR / CPA / ROAS。
2. **真实投放数据层**：只有用户实际投放后主动提供真实平台数据，系统才进入平台结果分析；届时必须先明确具体平台，不能默认抖音、淘宝、拼多多、小红书或京东。

当前最新功能重点是：

- 创意版本矩阵
- 创意方案分析
- 创意实验设计审计
- 核心机制字段与表层表达分离
- 判断多个版本是否真正形成有效对照
- 真实投放数据作为后续可选输入，而不是当前创意生成阶段的假设数据

### 下一阶段建议推进顺序

**第一优先：创意测试方案层**

在已经有“版本差异审计”的基础上，进一步形成：

- 本轮每个版本究竟在验证什么
- 每个版本的唯一主要测试轴
- 哪些版本存在多个变量同时变化
- 哪些版本只是换文案/换表面表达，没有形成有效机制对照
- 下一轮应该优先补哪个创意变量
- 输出“测试目的 → 版本设计 → 需要观察的真实结果”结构

注意：这里仍然不生成任何虚假投放结果。

**第二优先：创意质量与商品事实检查**

在进入真实投放之前，对每个成片继续检查：

- 商品外观是否与真实商品一致
- 核心功能是否被 AI 改写
- 卖点是否有商品资料支持
- 是否存在夸大、绝对化或未经证明的表达
- 画面是否遮挡商品主体
- 字幕、CTA、画面和商品事实是否互相矛盾
- 是否触发用户维护的禁用词/广告合规规则

**第三优先：真实投放数据适配层**

只有用户明确指定平台并提供真实数据后再建设对应适配器。

原则：

- 不默认平台
- 不伪造数据
- 不把模拟数据当真实数据
- 平台适配器与平台无关的创意分析层分离
- 真实数据进入后才允许进行结果比较、归因和下一轮反馈
