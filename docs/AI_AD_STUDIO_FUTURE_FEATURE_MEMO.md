## 1. AI 编导生成短剧

### 目标

增加完整的 **AI 编导 / AI 短剧创作能力**。

AI 不只是生成几个镜头，而是承担“编导”的角色：

**商品理解 → 短剧方向判断 → 剧情设计 → 人物设计 → 场景设计 → 冲突/反转 → 台词 → 分镜 → 镜头资产需求 → 生成/匹配素材 → 剪辑成片**

### 尚未实现的未来能力

- 根据商品自动判断适合的短剧类型。
- 根据目标人群、卖点、使用场景确定剧情方向。
- 自动设计人物、关系、场景、冲突、节奏和结尾。
- 自动生成完整短剧脚本。
- 自动拆分为可执行分镜。
- 自动判断每个镜头需要真人、AI生成画面、商品素材还是实拍素材。
- 支持多种剧情方案和商业转化方案。
- 最终输出完整的商品短剧。

### 原则

AI 编导不能简单套用固定行业模板，应根据商品本身重新判断最合适的故事机制。

## 2. 商业级剪辑决策层升级

A0–A33 已经完成基础剪辑生产链、多版本、检查和交付闭环，因此本节只保留**尚未实现的更高阶商业剪辑能力**。

### 尚未实现的未来重点

- 更高级的镜头衔接质量判断。
- 基于画面内容的动态节奏控制。
- 情绪递进与商业转化节奏联合优化。
- 音乐节奏与画面节奏的自动精细匹配。
- 更高级的卡点与转场决策。
- 字幕节奏与信息密度的联合优化。
- 商品展示节奏的精细控制。
- 根据广告目标动态调整开头、中段、结尾的结构强度。
- 建立真正面向商业使用的 **AI 剪辑决策层**，而不是主要依赖基础镜头排序、裁切和拼接。

### 核心要求

未来升级重点不是增加更多“剪辑动作”，而是让 AI 能够解释并自主决定：

**为什么这样剪 → 为什么这样排序 → 为什么这里快/慢 → 为什么这个卖点放这里 → 为什么这个版本应该这样变化。**

## 3. AI 短剧形式商品广告

### 目标

增加一种独立的商品广告生产模式：

**商品分析 → 判断适合的短剧世界/题材 → 设计剧情 → 商品进入剧情 → 用短剧形式自然介绍商品 → 完成转化**

### AI 自动判断方向

例如：

- 现代都市
- 古代
- 民国
- 职场
- 家庭
- 情侣
- 悬疑
- 搞笑
- 反转
- 情感
- 科幻
- 奇幻
- 生活场景
- 其他由商品分析后决定的形式

**不是固定从上述列表中机械选择。**

AI 应根据商品、人群、卖点、使用场景和广告目标，自主判断更合适的短剧形式。

### 商品融入方式

商品不是简单地贴在视频上，而是作为剧情中的真实商品信息进入故事：

**商品图片 / 外观 / 功能 / 使用方式 / 核心卖点**
→
**融入人物行为和剧情**
→
**自然完成商品展示**
→
**剧情推动商品认知**
→
**结尾完成转化**

### 重要真实性原则

商品的真实外观、核心功能、关键卖点不能因为 AI 生成剧情而被随意改变。

尤其是：

- 商品外观
- 商品结构
- 核心功能
- 关键使用方式
- 商品事实

需要优先保持真实。

## 4. 真实投放数据适配层

> **暂不开发。**

只有用户实际投放后主动提供真实平台数据，系统才进入这一层。

### 未来能力

- 接收真实平台投放数据。
- 明确具体平台后建立对应数据适配器。
- 比较不同创意版本的真实结果。
- 根据真实结果进行创意归因。
- 将真实结果反馈给下一轮创意设计。
- 建立“创意 → 投放 → 数据 → 学习 → 下一轮创意”的闭环。

### 数据边界

- 不默认抖音、淘宝、拼多多、小红书或京东。
- 不伪造 CTR / CVR / CPC / CPA / ROAS。
- 不把模拟数据当成真实投放结果。
- 平台适配器与平台无关的创意分析层分离。
- 只有真实数据进入后，才允许进行真实结果比较和反馈优化。
