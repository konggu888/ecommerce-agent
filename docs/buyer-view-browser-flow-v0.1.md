# 买家视角浏览器流程 v0.1

1. 用户点击“买家账号采集”。
2. 选择淘宝或拼多多。
3. 系统打开独立浏览器会话。
4. 用户本人完成平台登录。
5. 登录成功后输入关键词。
6. 浏览器在该买家会话中搜索。
7. 读取当前页面正常可见内容。
8. 标准化为 BuyerVisibleProduct。
9. 进入“对手/市场”数据层。
10. 博弈引擎使用该快照进行分析。

## 原则
- 会话隔离。
- 不把平台密码提交给本系统。
- 不保存平台登录凭据。
- 不绕过验证码、风控、权限或访问控制。
- 采集失败时保留失败原因，不伪造数据。
- 每条结果保存 URL 和 observedAt。
