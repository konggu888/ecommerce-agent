# 创业机会与可借力产品资源库

> 目标：从约人民币 10,000 元起步，在约 90 天内验证能否形成**月净利润不少于 5,000 元**的可持续业务。
>
> 原则：优先利用已经存在的产品、平台、供应链、分销/代理计划和成熟工具；不因发现需求就自行开发软件。没有真实客户、真实付款和完整成本证据，不得标记为已验证。
>
> 当前状态：资源库已建立；以下为初始条目。它们是研究线索，不代表已建立合作或已成交。

## 1. 证据与状态规则

### 证据等级
- **E0 — 线索**：搜索结果、宣传文案或未经核实的说法。
- **E1 — 官方/服务商公开页面**：可确认页面展示的功能、公开报价或政策；不能证明真实成交量或用户满意度。
- **E2 — 独立交叉验证**：多个独立来源支持关键事实，仍不等同于我方付费需求。
- **E3 — 我方真实验证**：有可复核的客户访谈记录、书面合作条款、真实付款/订单、成本和交付记录。

### 商业状态
- **待研究**：已发现产品/平台，合作模式、需求或经济账未验证。
- **待联系**：已确认可联系的官方渠道，但尚未联系。
- **已联系**：有联系记录；不等于对方回复。
- **合作条件已核实**：已取得可核实的代理、分销、API 或合作条款。
- **首单已成交**：有真实付款/订单凭证。
- **持续盈利已验证**：有多个周期的真实净利润记录。
- **淘汰**：关键条件不成立，记录淘汰原因，避免重复试错。

## 4. 当前商业假设（未验证）

### 假设 A：借助现有工具，向商家交付一个明确结果
不卖“AI 能力”，而是卖可验收的交付，例如商品资料整理、合规素材处理、订单异常排查或批量上架辅助。只有当商家愿意付费且工具/人工/获客成本后仍有利润，才继续。

### 假设 B：利用已有产品的合法渠道合作
优先寻找官方代理、分销、推荐佣金、API 合作或平台服务商计划。必须取得可核实条款；没有授权不转售、不冒充官方、不擅自转卖账号/API 密钥。

### 假设 C：使用成熟供应链做小批量实物测试
先核实采购成本、运费、平台费用、退货损耗、售后、竞争价格和获客成本。未完成成本核算前不囤货；公开零售价不能证明可盈利。

- 人工时间与人工成本：
- 获客成本：
- 退款、售后及坏账预留：
- 单笔净贡献：
- 每月需要的订单量：
- 真实付款证据：
- 90 天目标可行性判断：

计算规则：
- 单笔净贡献 = 实收收入 − 工具/采购成本 − 平台费用 − 获客成本 − 交付人工成本 − 退款售后等可归属成本。
- 达到月净利润 5,000 元所需订单量 = 向上取整〔(5,000 + 每月固定成本) ÷ 单笔净贡献〕。
- 单笔净贡献不大于 0，或订单量明显超出可交付能力时，停止该方案。

## 6. 下一轮优先动作

1. 对 R001–R009 逐个核查官方合作/代理/分销/API/服务商政策；仅引用官方条款确认授权与费用。
2. 记录能否个人参与、是否要求营业执照、保证金、预付费用、最低销售额和结算周期。
3. 同时寻找平台内公开的真实用户评价、成交证据或独立来源；把挂牌价与成交证据分开记录。
4. 从有低启动成本、可在 7 天内尝试首单的候选中，选择不超过 2 个做小规模验证。
5. 每次尝试记录真实接触人数、回复数、明确需求数、报价数、付款数、退款数、交付耗时和净利润。
6. 如果没有真实付款证据，不把“用户感兴趣”“公开页面存在”或“AI 评估可行”计入验证成功。

### 工具采用规则
1. **先试用现成工具，再考虑开发。** 只有现有工具无法完成经付费验证的关键需求，才评估自建。
2. **先看真实数据源标记。** real/API 与 mock 必须分开；模拟商品、销量、供应商和趋势不得进入采购决策。
3. **核对许可证。** GitHub 可见不代表可以随意商用；每次实际使用前检查 LICENSE、依赖许可证、品牌/素材权利和服务条款。
4. **核算总成本。** 除软件价格外，记录 API Token、云服务、人工清洗数据、部署维护和客户支持成本。
5. **优先本地、低固定成本。** 验证阶段不为尚无付费用户的项目租服务器或开发 SaaS。
6. **工具价值以节省时间和提高交付质量衡量。** 记录实际节省的工时、错误率、客户反馈和单笔净贡献，而不是按功能数量判断。

### 9.2 必须使用的价格计算规则

每个工具建立两套账：

**A. 现金支出（实际支付）**
- 一次性：购买/授权、设备、部署、迁移。
- 持续性：月费/年费、API/Token、云主机、数据订阅、平台手续费。
- 交易性：每单佣金、支付费、退款损耗。
- 退出性：取消订阅、导出数据、迁移与删除数据的成本。

**B. 完整经济成本（即使没有付款也不能忽略）**
- 安装配置、数据清洗、人工复核、维护、客户支持所耗工时 × 合理时薪。
- 免费工具不等于零成本；开源工具不等于无需维护。
- 本地部署不等于没有成本，只代表可能不产生新增云服务账单。

**每单净贡献公式：**
`每单净贡献 = 实收金额 - 交易费用 - 工具/API分摊 - 数据采购/采集成本 - 交付人工成本 - 获客成本 - 退款售后预留`

**工具方案月度成本：**
`月总成本 = 固定订阅/主机/数据费 + API实际用量 + 交易性费用 + 人工维护成本`

**是否值得购买：**
`净节省 = 使用工具前的人工成本 - 使用工具后的人工成本 - 工具现金费用 - 新增错误/返工成本`

如果净节省不为正，或工具并未提升客户结果，不购买/不续费。

**90 天目标校验：**
- 每个候选都计算一次性启动现金支出、每月固定支出、单笔净贡献、盈亏平衡订单量。
- 在获得首批真实付款前，默认不新增服务器、付费 API 订阅、批量采购或广告预算。
- 价格记录要带“价格核验日期、计价单位、套餐限制、是否含税、是否有免费额度、来源链接”；价格变动时更新旧记录而非覆盖历史。

## 11. 国内电商工具成本与采购决策规则

每个工具按具体国内平台分别记录，不将海外独立站工具混入当前执行清单。至少记录：
1. 平台（淘宝/天猫、拼多多、抖音、京东、1688 等）与所需店铺权限；
2. 官方价格、计价单位、按月/按年、每店/每账号/按订单量计费；

5. 真实订单/退款/SKU 成本数据是否可导入、计算口径是否准确、能否导出和删除数据；
6. 实际节省工时与单笔净贡献；
7. 价格核验日期、官方链接和证据等级。

**国内电商优先级：**
- 第一优先：免费经营核算/复盘工具，用脱敏真实数据对照测试。

- 第三优先：客服、ERP、API 自动化等持续付费服务，先计算每月能省下的人工成本和盈亏平衡订单量。
